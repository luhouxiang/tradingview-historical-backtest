## 本次讨论形成的核心结论

### 1. 三层体系

策略不只是“一、二、三类买卖点”，而是三层：

1. 走势状态层：上涨、下跌、盘整、中枢震荡、中枢移动。
2. 结构信号层：走势完成、趋势背驰、盘整背驰、B1/B2/B3 与卖点镜像。
3. 指标辅助层：MACD、均线、成交量、BOLL、分型＋5周期均线、`Zn`。

### 2. 结构优先

先确定级别、完成组件、中枢、走势类型和待比较走势段，再使用指标。
指标不能脱离结构直接生成买卖点。

### 3. 标准项目口径

- 标准策略以线段中枢为基础。
- 笔类中枢只能作为独立实验分支。
- 中枢核心区按闭区间处理。
- B3/S3 使用严格 `>` / `<`，触边归为中枢延伸。
- 所有价格先转换为整数最小跳动单位。
- 每个信号必须分离理论端点与可交易确认时点。

### 4. 反未来函数

任何“完成”都必须能在当时由已完成的更低级别结构确认。未完成末段的
MACD面积天然偏小，只能形成候选背驰，不能确认背驰。回测成交只能发生在
`confirmed_at` 或其后。
