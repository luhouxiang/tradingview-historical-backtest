# 01 讨论脉络与决策摘要

以下是按议题演进整理的讨论脉络。它是结构化摘要，不是逐字时间轴。

## 阶段一：从线段基础询问可程序化策略

起始问题聚焦于：在已经能画出线段的基础上，可以构建哪些缠论策略算法。
讨论逐步把问题拆成：

1. 线段如何成为中枢组件；
2. 中枢如何形成、延伸、扩展和结束；
3. 哪些信号能直接来自结构，哪些只能由指标辅助；
4. 如何消除实时计算中的未来函数。

工程上确定：标准策略采用线段中枢；笔类中枢保留为独立实验分支，不能
与标准信号混用。

## 阶段二：中枢与五类核心信号

讨论重点扩展到：

- 趋势背驰与第一类买卖点；
- 第二类买卖点；
- 第三类买卖点；
- 盘整背驰；
- 中枢震荡。

形成的关键结论：

- 趋势背驰必须先有趋势，即至少两个同级、同向、互不重叠中枢。
- 末段不创新高/低时不能确认标准趋势背驰。
- 一买/一卖是原趋势结束点，不等于反趋势已确认。
- 二买可以低于一买，但属于弱结构，须有盘整背驰和低级别完成证据。
- 三买/三卖至少需要“前三段构成中枢＋离开段＋第一次回试段”。
- 项目把中枢视为闭区间，所以三买/三卖用严格 `>` / `<`；触边继续中枢。
- 盘整背驰后可能回中枢，也可能演化成三买/三卖，不能预设方向。
- 中枢震荡内部使用低级别买卖点，同级中枢由三买/三卖结束。

## 阶段三：实时确认与回测

讨论明确区分四个概念：

| 字段 | 含义 |
|---|---|
| `endpoint_time` | 理论结构端点发生时间 |
| `confirmed_at` | 已完成低级别结构使其可被确认的时间 |
| `signal_price` | 理论买卖点价格 |
| `executable_price` | 确认后实际可成交价格 |

未完成的末段天然拥有较小的MACD面积，不能用完整前段与未完成末段直接
确认背驰。允许先产生候选事件，但只能在低级别结束点确认后升级。

## 阶段四：补入“走势/走势类型”

用户指出体系中还缺少“走势”。讨论随后把顶层体系改写为三层：

1. 走势状态：上涨、下跌、盘整、中枢震荡、中枢移动。
2. 结构信号：走势完成、背驰、三类买卖点。
3. 指标辅助：MACD、均线、成交量、BOLL、分型和 `Zn`。

并归纳出固定级别操作状态：

- 中枢内：等待或使用低级别信号做震荡；
- 中枢下、无三卖：仍可能是震荡，比较向下段力度；
- 中枢下、已有三卖：回避同级做多，等待下跌走势完成；
- 中枢上、无三买：等待第一次完整回试；
- 中枢上、已有三买：进入中枢上移处理。

## 阶段五：从108课整理“结构＋指标”方法

用户要求从原文中寻找中枢或买卖点结合指标的交易方法。讨论把指标角色
分为三类：

- 力度比较：MACD、成交量；
- 阶段和强弱辅助：BOLL、均线、分型、`Zn`；
- 风险过滤：MACD零轴。

整理出的主要方法：

1. MACD＋趋势背驰＋一买一卖；
2. MACD＋盘整背驰＋中枢震荡；
3. MACD或成交量＋二买二卖内部完成；
4. BOLL辅助一、二类买卖点和中阴结束；
5. 顶底分型＋5周期均线＋低级别中枢；
6. 成交量和力度过滤大级别中枢的快速突破；
7. `Zn` 中枢震荡监视器；
8. MACD零轴风险过滤；
9. 早期5/10均线“吻”系统单独保存，不与严格中枢信号混同。

## 阶段六：整理为策略目录

最终形成的策略家族包括：

- 下跌＋上涨高效率法；
- 固定级别中枢决策树；
- 中枢震荡差价法；
- 三买后的中枢移动持有法；
- 第一个中枢三买轮动法；
- 大级别核心仓位＋次级别短差；
- 趋势背驰反转；
- 盘整背驰回中枢；
- 小转大二买/二卖补充；
- 快速大级别突破中的低级别三买/三卖。

具体条件、排除项和事件字段见 `04_signal_rules.md`、
`05_strategy_catalog.md` 与 `specs/strategies.json`。
