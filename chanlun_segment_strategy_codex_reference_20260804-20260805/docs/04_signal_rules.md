# 04 五类信号与三类买卖点规则

## 1. 趋势背驰与 B1/S1

### 1.1 结构前提

典型趋势写成：

\[
a+Z_1+b+Z_2+c
\]

其中：

- `Z1`、`Z2` 为同级别、同向排列、互不重叠中枢；
- 整体已达到上涨或下跌趋势定义；
- `b` 与 `c` 是围绕后部中枢可比较的同向运动；
- 上涨末段 `c` 必须创新高，下跌末段 `c` 必须创新低；
- `c` 的结构力度弱于 `b`；
- `c` 内部低级别结束结构确认其完成。

不同课次常用 `A/B/C` 或 `a/A/b/B/c` 记号。实现不要依赖字母名，必须依赖
角色字段：`pre_last_centre_leg`、`last_centre`、`final_leg`。

### 1.2 MACD辅助

最后中枢通常使 DIFF/DEA 回到零轴附近。上涨比较红柱，下跌比较绿柱：

- 柱面积衰减；
- 柱体最大高度衰减；
- DIFF/DEA极值不再创新高/低。

上述仅是力度证据，不能绕过趋势结构。

### 1.3 确认与买卖点

- 下跌趋势底背驰的 `c` 端点：B1；
- 上涨趋势顶背驰的 `c` 端点：S1。

若 `c` 未完成，可发 `trend_divergence_candidate`。低级别结束确认到达后才发
`B1_confirmed` / `S1_confirmed`。

### 1.4 排除项

- 只有一个同级别中枢；
- 两个中枢级别不同；
- 中枢重叠，只能视为更大中枢/震荡；
- 末段未创新高/低；
- 仅有MACD价格背离；
- 完整前段与未完成末段直接比较面积；
- 未保存确认时点便回填端点成交。

### 1.5 B1/S1之后

趋势背驰只说明原趋势结束，随后可能：

1. 最后中枢级别扩展；
2. 形成更高级别盘整；
3. 形成同级或更高级反趋势。

B1/S1 不是新趋势已经成立的同义词。

## 2. B2/S2

### 2.1 标准顺序

买侧：

\[
B1\rightarrow U_1\rightarrow D_1\rightarrow B2
\]

- `U1`：从B1起第一个已完成次级别向上走势；
- `D1`：随后第一个已完成次级别向下回试；
- `D1` 的结束点：B2；
- `D1` 的结束应由其内部次级别B1或等价完成结构确认。

卖侧镜像：

\[
S1\rightarrow D_1\rightarrow U_1\rightarrow S2
\]

### 2.2 强弱分类

| 强度 | B2位置 | 条件与含义 |
|---|---|---|
| `strong` | 位于原最后中枢上方并同时是B3 | 二、三买合一，常见快速V形反转 |
| `normal` | 不低于B1 | 一般回试结构 |
| `weak` | 低于B1 | 必须形成盘整背驰并有低级别完成确认，常对应中枢扩张 |

S2完全镜像。

### 2.3 相对中枢位置

- 中枢下：较弱，扩张概率高；
- 中枢内：扩张或新生均可能；
- 中枢上：较强，可能与B3重合。

B1不能与B2/B3重合；B2可以与B3重合。

### 2.4 小转大

目标级别没有标准B1、但小级别背驰引发大级别转折时，B2可能承担目标级别
的可交易确认。必须标为 `small_to_large_B2`，不能与普通B2混统计。

### 2.5 排除项

- B1未确认；
- B1后的第一段向上走势未完成；
- 第一次回试未完成；
- 回试创新低后既无盘整背驰也无次级别结束确认；
- 只有一根K线或一笔局部反弹；
- 因“回踩没破”而跳过完成性检查。

## 3. B3/S3

### 3.1 必要结构

1. 三个已完成次级别组件形成中枢；
2. 一个已完成次级别走势离开中枢；
3. 第一次反向回试/回抽完成；
4. 回试完全不接触核心。

至少需要五个次级别组件。

### 3.2 原文与项目口径

| 信号 | 原文字面 | 项目硬规则 |
|---|---:|---:|
| B3 | 回试低点不跌破 `ZG`，即 `>=` | `retest_low > ZG` |
| S3 | 回抽高点不升破 `ZD`，即 `<=` | `retest_high < ZD` |

差异原因：项目把中枢当闭区间，等于边界仍有接触。此工程约定用于避免同一
走势同时成为“中枢延伸”和“三买/三卖”。

### 3.3 限制

- 必须是第一次完整回试；
- 离开走势可以从中枢内部开始，不要求整段都在外部；
- 必须针对当前分解中最近的同级别中枢；
- 突破时只是候选；
- 回试完成后才能确认；
- 触及/进入核心即恢复中枢延伸；
- B3/S3后可能是趋势，也可能扩展为更高级别中枢。

## 4. 盘整背驰

### 4.1 标准结构

\[
a+Z+c
\]

条件：

1. 当前走势只有一个同级别中枢；
2. `a`、`c` 方向相同；
3. `c` 力度弱于 `a`；
4. `a`、`c` 可以是盘整走势，不要求都是趋势；
5. 通过 `c` 内部低级别结构确认结束。

`c` 可以创新高/低，也可以不能突破 `a` 极值。它不是标准趋势B1/S1，
应使用 `consolidation_divergence` 或 `class_B1_like` 标签。

### 4.2 与趋势背驰的区别

| 项目 | 趋势背驰 | 盘整背驰 |
|---|---|---|
| 同级中枢数 | 至少2个 | 1个/同一中枢震荡 |
| 中枢关系 | 同向且互不重叠 | 围绕同一中枢 |
| 末段必须创新高/低 | 是 | 否 |
| 信号性质 | 标准B1/S1 | 震荡或类买卖点 |
| 后续 | 原趋势结束 | 回中枢或转化B3/S3 |

### 4.3 两个分支

向上离开出现盘整顶背驰：

- 回跌进入中枢：继续震荡；
- 第一次回跌不进入中枢：B3。

向下离开出现盘整底背驰：

- 反弹进入中枢：继续震荡；
- 第一次反弹不能进入中枢：S3，原“底背驰买入”逻辑失效。

## 5. 中枢震荡

### 5.1 状态条件

- 前三个完成组件已经确认核心 `[ZD,ZG]`；
- 核心固定；
- 后续同向震荡段仍与核心存在接触/回归；
- 尚无确认B3/S3；
- 九段升级规则尚未完成高级别替代。

### 5.2 信号方法

不是机械地“到ZD买、到ZG卖”，而是比较最近相邻同向震荡段：

| 当前段 | 比较对象 | 力度衰减 | 行动候选 |
|---|---|---|---|
| 向下 | 最近前一向下段 | 是 | 盘整底背驰，区间套找低级别B1 |
| 向上 | 最近前一向上段 | 是 | 盘整顶背驰，区间套找低级别S1 |

同级别中枢震荡中不生成新的同级B1/B2；执行使用低级别买卖点。

### 5.3 状态切换

- B3：停止做空差价，进入中枢上移；
- S3：停止向下回补，进入中枢下移；
- 回试进入或触及核心：中枢继续；
- 总计九段以上延伸：进入高级别中枢识别。

外围震荡可以远超核心边界，所以 `[ZD,ZG]` 不是机械止损线。

## 6. `Zn` 监视器

中枢中轴：

\[
Z=\frac{ZD+ZG}{2}
\]

第 `n` 个次级别震荡区间的中点：

\[
Z_n=\frac{H_n+L_n}{2}
\]

- `Zn > Z`：偏强；
- `Zn < Z`：偏弱；
- 连续上移/下移：强弱累积变化；
- 越过边界：变盘预警，不是B3/S3确认；
- `Zn` 超过边界但未形成三买卖点，常提示级别扩展。
