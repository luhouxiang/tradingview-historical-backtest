# 06 指标的角色、用法与边界

## 1. 总原则

指标的使用顺序固定为：

```text
确定级别和中枢
→ 确定走势类型与待比较走势段
→ 选择能清楚表达两段力度的指标周期
→ 产生辅助证据
→ 等结构完成确认
```

不能先在指标上找“背离”，再反向拼接中枢和走势。

MACD、均线、BOLL等都由价量衍生，彼此不独立。多个技术指标同意不能简单
相乘为更高置信度。

## 2. MACD

### 2.1 趋势背驰力度比较器

结构前提满足后，可比较：

- 柱面积；
- 柱体最大伸长高度；
- DIFF/DEA极值；
- 最后中枢是否把黄白线拉回零轴附近。

上涨比较红柱，下跌比较绿柱。具体颜色应由数据字段而非UI颜色决定。

### 2.2 盘整背驰

对 `a+Z+c` 或相邻同向震荡段比较力度。若 `c` 尚未完成，其柱面积只能是
临时值。可以发候选，但不能确认。

### 2.3 快速走势的柱高

极短、急促走势中，柱体冲击历史常见伸长极限但不能突破，可作超短回调预警。
这不是一般背驰公式，不能扩展到所有周期或直接升级为标准买卖点。

### 2.4 零轴风险过滤

选择个人最低操作周期（例如30m或60m）：

- 黄白线进入零轴下并反抽确认后，过滤普通多头策略；
- 重新稳定站上零轴后恢复观察；
- 高熟练度下，结构背驰可以配置为例外。

这是风险过滤器，不是B1/B2/B3生成器。

## 3. 成交量

允许的角色：

- 辅助比较二买二卖内部走势力度；
- 辅助确认大级别中枢的快速猛烈突破；
- 早期均线系统中识别第一次缠绕前放量过大带来的骗线/延长风险。

禁止：

- 单独由放量确认B3；
- 用不同交易时段、不同合约或未经换月调整的量直接比较；
- 忽略涨跌停、集合竞价和交易制度导致的量异常。

## 4. BOLL

| 状态 | 讨论中的辅助含义 |
|---|---|
| 价格在上轨以上 | 上涨超强，常见于中枢上移 |
| 价格在下轨以下 | 下跌超强，常见于中枢下移 |
| 从轨外回到轨内 | 从超强进入一般/中阴状态 |
| 再创新高/低但不能重返超强区 | 辅助B1/S1 |
| 轨道转向形成压力/支撑 | 辅助B2/S2 |
| BOLL收口 | 提示较低级别中阴过程结束或级别扩展，常伴随B3/S3 |

BOLL比MACD更依赖经验，只能预警和辅助。周期对应关系必须配置，不应默认
“5分钟结构就看5分钟BOLL”。

## 5. 早期5/10均线“吻”系统

定义：

- 短均线在长均线上：多头状态；
- 短均线在长均线下：空头状态；
- 飞吻：短均线略走平后沿原方向继续；
- 唇吻：靠近长均线但不穿越后继续；
- 湿吻：穿越或反复缠绕。

早期候选：

- 空头状态最后一次缠绕后的背驰下跌：`ma_B1_candidate`；
- 转为多头后第一次缠绕的回调：`ma_B2_candidate`。

这是正式中枢体系形成前的经验语言。只有同时满足后来的中枢、走势、级别
与完成定义时，才能升级为严格B1/B2。

## 6. 顶底分型＋5周期均线＋小级别中枢

以上涨后的顶分型为例：

1. 大级别出现顶分型；
2. 检查小级别S1/S2；
3. 有效跌破5周期均线，延伸成向下笔的可能性增加；
4. 小级别中枢出现S3且不发生扩张，进一步确认调整；
5. 若未有效跌破5周期均线且小级别出现盘整底背驰，可能只是中继并可寻找回补。

底分型镜像。分型和均线是辅助，最终由小级别买卖点和中枢移动确认。

## 7. `Zn` 中枢震荡监视器

\[
Z=(ZD+ZG)/2,\qquad Z_n=(H_n+L_n)/2
\]

它可用于：

- 标记每次震荡相对中轴偏强/偏弱；
- 观察连续上移/下移；
- 在 `Zn` 越界时发变盘预警；
- 与BOLL时间预警结合观察级别扩展。

`Zn` 越过 `ZD/ZG` 不是B3/S3，因为三买卖点仍需要完成离开和第一次回试。

## 8. 建议辅助证据结构

```json
{
  "indicator_name": "MACD|VOLUME|BOLL|MA|FRACTAL|ZN",
  "role": "force_comparison|phase_auxiliary|risk_filter|warning",
  "analysis_level": "...",
  "observed_at": "...",
  "comparison_leg_ids": ["..."],
  "metric": "histogram_area|peak_height|diff_extreme|...",
  "result": "weaker|stronger|neutral|not_comparable",
  "provisional": true,
  "parameters": {}
}
```

`provisional=false` 也不等于结构确认；它只说明指标测量窗口已完成。
