# 09 会话图表附件说明

本目录保留三张会话原始PNG。说明只记录可见元素和本次讨论可用的观察点，
不对具体品种作买卖建议。

## `chart_01_centre_oscillation_macd_volume.png`

可见：

- K线上的蓝色折线/线段；
- 多个紫色中枢矩形；
- 红色椭圆圈出的长时间横向震荡区域；
- 下方MACD与成交量；
- 右侧后段出现向下离开、下方新紫色区间及快速反弹回落。

适合作为测试议题：

- 核心区与外围震荡不能混同；
- 在红圈震荡内比较相邻同向段力度；
- 离开发生时先标候选，等待第一次回试；
- 边界不应被当作机械止损线。

## `chart_02_segments_centres_ma_macd_volume.png`

可见：

- 蓝色线段；
- 三个主要紫色中枢区域；
- MA20、MA60；
- MACD与成交量；
- 前段下行、中央反弹后再下行、右侧进入横向中枢。

适合作为测试议题：

- 同级中枢之间的连接与趋势/扩张判别；
- 均线只能辅助阶段判断，不能替代中枢；
- 最近中枢决策树；
- 走势多义分解需要稳定优先级。

## `chart_03_uptrend_centres_and_breakdown.png`

可见：

- 左侧低位紫色中枢；
- 中部上移至更高紫色中枢；
- 上方延伸/震荡；
- 右侧出现快速向下运动及新的较小紫色区间；
- MA20/MA60、MACD与成交量。

适合作为测试议题：

- 中枢上移阶段不应继续做同级短差；
- 新中枢形成后切换回震荡状态；
- 上移结束、卖点与快速离开之间的确认延迟；
- 趋势背驰与仅有指标背离的区别。

## 使用限制

图片没有随包附带可重放行情数据、线段端点表或中枢坐标，因此只能用作
视觉说明，不能作为数值单元测试的唯一真值。若要做golden test，应另存：

- 原始K线；
- 最小tick；
- session规则；
- 线段端点ID和确认时间；
- 中枢核心与外围坐标；
- 期望候选/确认事件序列。
