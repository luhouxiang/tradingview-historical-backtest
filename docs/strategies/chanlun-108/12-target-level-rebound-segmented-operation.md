# 目标级别反弹/回调分段操作

## 身份与出处

- 运行 ID：`target_level_rebound_segmented_operation`，版本 `1.0.0`。
- 理论母项：`ALG-STR-008`。
- 出处：[第47课](https://chanlun108.cn/chanzhongshuochan108ke/47.html)、[第56课](https://chanlun108.cn/chanzhongshuochan108ke/56.html)、[第98课](https://chanlun108.cn/chanzhongshuochan108ke/98.html)、[第107课](https://chanlun108.cn/chanzhongshuochan108ke/107.html)。核心约束是：目标级别反弹至少形成一个该级别中枢，但不能预设第二个同向段一定创新高。

## 当前算法

1. 固定对象图 `segment_rebound_rhythm_v1`，只用已确认标准 B1/S1 启动目标级别反弹/回调；盘整背驰类一信号不参与。
2. 初始以配置总手数入场。第一条目标方向段完成后部分兑现；第一条反向段未严格穿过来源极值时回补，等于来源极值也算未破坏。
3. 首个目标级别中枢确认后等待关联 B3/S3。
4. 目标方向三类点必须同时拥有完成的离开段、回试段和首个跟随段；跟随段严格创新极值且端点无背驰才转入 `TREND_HANDOFF`。
5. 相反三类点、严格破坏来源极值、成本后空间不足、跟随段不创新高/背驰或来源 revision 都会退出/重置；空头回调完全镜像。
6. 部分减仓和回补使用正式数量动作，执行层按 FIFO 批次分摊成本。

## 可能命中的条件

需要先出现稀缺的标准趋势 B1/S1，随后形成可分段的目标级别节奏。较有利的是反转后有至少一升一降的清晰段落，并在首中枢后形成非背驰三类点；不利的是只有一次急促反弹、成本吞噬分段空间，或来源极值很快被破坏。

## 优点

- 不假设反弹第二段一定创新高，第一段即可兑现部分仓位。
- 仓位数量、减仓、回补和趋势移交都进入正式成交事实。
- 标准趋势转折与盘整类信号严格隔离。

## 缺点与风险

- 前置标准 B1/S1 极少，长期可能没有足够样本。
- 状态和数量动作复杂，交易成本、保证金和成交限制影响大。
- 当前级别图谱固定为一个已实现 profile，未覆盖所有递归节奏。
- 分段操作可能在强单边中提前减仓，降低趋势收益。
