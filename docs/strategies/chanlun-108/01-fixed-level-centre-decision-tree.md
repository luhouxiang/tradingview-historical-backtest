# 固定级别中枢决策树

## 身份与出处

- 运行 ID：`fixed_level_centre_decision_tree`，版本 `1.2.0`。
- 理论母项：`ALG-STR-001`，证据等级为 `DERIVED`。
- 主要出处：[第18课](https://chanlun108.cn/chanzhongshuochan108ke/18.html)的中枢连接和离开/回拉逻辑、[第20课](https://chanlun108.cn/chanzhongshuochan108ke/20.html)的 `ZD/ZG` 与三类点、[第21课](https://chanlun108.cn/chanzhongshuochan108ke/21.html)的三类买卖点完备性、[第49课](https://chanlun108.cn/chanzhongshuochan108ke/49.html)的相对最近中枢状态划分。

原课提供的是围绕中枢的位置和买卖点关系，不是这一名称的现成程序；本策略是把这些规则整理成可回放的五状态工程决策树。

## 当前算法

1. 只消费已确认的标准线段中枢，选择开始时间和确认时间最新的中枢作为当前中枢。
2. 以收盘价相对冻结核心分类：`close > ZG` 为中枢上方，`close < ZD` 为中枢下方，接触边界或位于 `[ZD,ZG]` 内都算中枢内。
3. 检查是否已有严格关联当前中枢的标准 B3/S3，形成 `inside`、`above_without_B3`、`above_with_B3`、`below_without_S3`、`below_with_S3` 五状态。
4. 只在 `above_with_B3` 开多、`below_with_S3` 开空；单根 K 线站上/跌破边界不能代替三类点。
5. 多仓回到中枢内或中枢下方时平仓；空仓回到中枢内或中枢上方时平仓。所有动作在结构确认 K 线发布，执行层默认下一根开盘成交。

## 可能命中的条件

程序触发需要同时满足：已有标准中枢、严格三类点已完成并关联该中枢、价格仍位于突破方向一侧、方向开关允许交易。更可能取得正收益的行情是中枢完成后出现干净的方向离开，首次回试守住边界，随后延续足以覆盖确认延迟和交易成本。

不会命中的典型情况包括：只有价格突破而没有完整离开/回试结构、三类点仍是候选或类三、信号属于旧中枢、价格在确认时已经回到核心内。

## 优点

- 状态少、解释直接，每次决策能追溯到当前中枢和三类点。
- 不靠屏幕位置、单根 K 线或 MACD 猜测三类点。
- 多空镜像，适合作为其他复杂策略的状态基线。

## 缺点与风险

- 固定线段级别投影不等于完整递归级别；中枢切换可能让状态突然重置。
- 只看最近中枢和当前收盘位置，未包含后继走势力度、流动性和趋势背驰质量。
- 确认后才入场，快速突破可能已错过大段行情；假突破会来回产生成本。
