# 底部/顶部构造状态机

## 身份与出处

- 运行 ID：`bottom_top_construction`，版本 `1.0.0`。
- 理论母项：`ALG-STR-009`。
- 出处：[第82课](https://chanlun108.cn/chanzhongshuochan108ke/82.html)、[第88课](https://chanlun108.cn/chanzhongshuochan108ke/88.html)、[第99课](https://chanlun108.cn/chanzhongshuochan108ke/99.html)、[第108课](https://chanlun108.cn/chanzhongshuochan108ke/108.html)，对应分型强弱、图形生长和底/顶成功失败分类。

## 当前算法

策略包含严格交易层和粗略观察层，两者不能混用。

1. 精确底部只由已确认标准 B1 启动，并锁定 `start_bar_index` 与 B1 端点一致的首个已确认标准中枢；该中枢最先出现 B3 为成功，最先出现 S3 为失败。
2. 精确顶部由标准 S1 启动，首中枢后 S3 成功、B3 失败，完全镜像。
3. 精确构造成功后持仓穿过底顶连接走势，直到新的标准一类点移交；失败或来源 B1/S1、中枢、结果三类点 revision 时退出重置。
4. 粗略底分型使用中间处理后 K 线闭区间：严格跌破下沿失败，确认后连续收盘严格站上上沿成功；顶部镜像，等于边界既不完成也不失败。
5. 粗略层始终标记 `coarse_zone_executes_trade=false`，只发布观察状态和图表事件，绝不因看到分型区间盲目开仓。

## 可能命中的条件

精确交易命中要求标准 B1/S1、由其引发的首个中枢、以及最先到达的三类点顺序完整。较有利的是趋势转折后成功构造底/顶并形成长连接走势；较差的是只有局部分型、标准一类点稀缺，或首中枢先出现失败方向三类点。

## 优点

- 把“底/顶正在形成、成功、失败”做成显式状态，不把分型直接等同反转。
- 精确层与粗略观察层彻底分离，避免辅助图形制造交易。
- 来源 revision、边界等号和连接走势持有均有因果规则。

## 缺点与风险

- 精确链条很长，信号少且确认较晚。
- 持有到新标准一类点可能出现较大浮盈回撤或期末未平仓。
- 粗略层事件很多，若 UI 使用者误读为买卖信号会造成认知风险。
- 当前粗略有效根数是工程参数，不是普适市场常数。
