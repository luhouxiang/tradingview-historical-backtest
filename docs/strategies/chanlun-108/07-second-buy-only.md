# 只做第二类买点

## 身份与出处

- 运行 ID：`second_buy_only`，版本 `1.2.0`。
- 理论母项：`ALG-STR-002`。
- 出处：[第14课](https://chanlun108.cn/chanzhongshuochan108ke/14.html)、[第17课](https://chanlun108.cn/chanzhongshuochan108ke/17.html)、[第53课](https://chanlun108.cn/chanzhongshuochan108ke/53.html)、[第86课](https://chanlun108.cn/chanzhongshuochan108ke/86.html)、[第101课](https://chanlun108.cn/chanzhongshuochan108ke/101.html)。这些课程覆盖 B1 后第一次回试、二买三种相对位置和“小转大”等边界。

## 当前算法

1. 默认只接受已确认标准 B2；参数 `allow_class_like_entries=true` 时也接受明确标记为 `signal_class=class_like` 的已确认 `class_buy_2`。两类信号保留不同的 `reason_code`，类二买不会被改名为标准二买。候选点和缺少完整已确认线段链的事件始终拒绝。
2. 按结构分成最强、一般、最弱三类；三类可独立开关。默认最强/一般 2 手，最弱 1 手，且最弱仓位不得高于另外两类。
3. 入场后只检查与 B2 回试端点连续的第一条已确认上升段。
4. 该段未严格创新高或确认顶背驰时退出；若同点/同来源确认 B3，后继上升创新高且无背驰，则发布 `handoff_to_B3_trend`，把持有逻辑移交三买趋势分支。
5. 标准卖点、B2 来源修订或风险过滤也会终止持仓；成交仍在下一可执行 K 线。

## 可能命中的条件

标准模式必须先有标准 B1，再有第一次完成回试形成标准 B2，并通过配置接受对应分支。启用类二买时，其来源是盘整背驰后的首次完成回试，仍须有完整的“上升段—回试下降段”链。较有利的是反转后第一次回试结束、随后上升创新高；较差的是 B2 后反弹无力、确认时已靠近前高，或最弱 B2 继续破坏 B1 结构。

## 优点

- 把 B2 的三种结构差异显式映射到是否参与和仓位。
- 只评估第一条后继段，退出与趋势移交边界清楚。
- 默认不使用类二点；需要扩大样本时必须显式开启，正式 run 会记录该参数和不同的入场原因码。

## 缺点与风险

- 强依赖标准 B1/B2 识别，严格条件会导致长期无交易。
- 当前实现只做买点多头，没有对称的第二类卖点策略。
- B2 分类和默认手数未经跨品种样本外验证。
- 第一后继段确认才判断失败，退出可能有明显滞后。

## 当前证据

AOL9 当前 71149 根全量事实中标准 B2 为 0、已确认类二买为 62；因此默认标准模式应为 0 笔，而启用 `allow_class_like_entries` 后才允许消费后者。全区间、下一根开盘成交并启用统一风控的复测产生 18 笔完整交易（36 个开平信号），首个入场原因码为 `CONFIRMED_CLASS_LIKE_NORMAL_B2_ENTRY`；这只证明执行链已贯通，不构成收益或泛化能力结论。此前界面还把正式回测执行区间固定为最后 3000 根，现已改为数据集全区间；全历史仍从首根建立因果状态，成交只会发生在 run 明确记录的执行区间内。
