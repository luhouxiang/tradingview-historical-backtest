# MACD 与均线辅助项复核

## 结论

108 课算法目录中没有遗漏两个“本应直接下单”的策略。`ALG-AUX-001` 均线吻旧系统和 `ALG-AUX-002` MACD 零轴防守被有意实现为非交易辅助项：前者是被后期严格几何重新定位的早期简化系统，后者是风险开关/力度证据。把两者直接相乘仍然只是两个指标条件的组合，不能获得标准缠论买卖点的结构身份。

本次因此没有把“均线吻 + MACD”升级为标准策略，而是新增两个“标准 B3/S3 + MACD 方向确认”策略。三类点负责产生交易机会，MACD 只负责放行或拒绝，这个职责边界更实用，也更容易用基准策略做增量对照。

## 均线吻旧系统为什么不交易

`aux_ma_kiss_legacy` 对应 `ALG-AUX-001`，来源为[第11课](https://chanlun108.cn/chanzhongshuochan108ke/11.html)、[第12课](https://chanlun108.cn/chanzhongshuochan108ke/12.html)、[第14课](https://chanlun108.cn/chanzhongshuochan108ke/14.html)和[第72课](https://chanlun108.cn/chanzhongshuochan108ke/72.html)。当前实现识别飞吻、唇吻、湿吻，并能发布旧系统 B1/B2 候选；可选 MACD 代理还会判断空头吻之后的新低是否出现负柱收缩。

它没有形成正式策略的原因是：

1. 第72课明确说明早期均线系统是简化表述，后期包含关系、分型、笔、线段、中枢和走势定义具有更高优先级。
2. “最后一次吻”若在全历史结束后回看才知道，会产生未来函数；实时只能发布“截至当前满足条件的候选”。
3. 均线周期、接近阈值、走平阈值对品种和周期敏感，证据等级只能是 `AUXILIARY/LEGACY`。
4. 当前事件明确写入 `standard_signal=false`、`execution_allowed=false`，也没有开仓、退出和仓位状态机。

它适合做可视化、基线模型或结构策略的非强制过滤特征，不应改名成标准 B1/B2。若未来要做可交易的“旧系统基线”，也必须作为独立 `legacy` 研究角色，绩效不能与标准缠论策略混为一谈。

## MACD 零轴防守为什么不交易

`aux_macd_zero_axis_defense` 对应 `ALG-AUX-002`，来源为[第24课](https://chanlun108.cn/chanzhongshuochan108ke/24.html)、[第25课](https://chanlun108.cn/chanzhongshuochan108ke/25.html)、[第50课](https://chanlun108.cn/chanzhongshuochan108ke/50.html)和[第103课](https://chanlun108.cn/chanzhongshuochan108ke/103.html)。当前规则是：DIFF 与 DEA 同时严格低于负缓冲并连续达到确认根数时关闭参与；两线同时严格高于正缓冲并连续确认后恢复参与候选。等于边界或只有一条线越界都不成立。

它没有形成独立交易策略的原因是：

1. 第24、25、50课要求先确定结构可比的 `a/c` 段，再用 MACD 比力度；MACD 不是背驰定义，更不能单独制造 B1/S1。
2. 第103课的零轴规则是面向不能执行完整结构算法时的防守或组合风险门，不给出完整的入场、退出、反手和仓位状态机。
3. 单独使用零轴会产生严重周期依赖；同一时刻在 5 分钟和 60 分钟上可能方向相反，而 K 线周期又不等于缠论结构级别。
4. 当前输出只含 `aux_macd_risk_off/risk_on_candidate`，明确 `execution_allowed=false`、`opens_position=false`。

## 为什么不优先做“均线吻 + MACD”

两个辅助条件结合可以减少事件数量，但不能解决结构缺失：均线吻仍是旧系统候选，MACD 仍是力度/风险证据。若让组合直接下单，就会违反“MACD 不能独立制造标准买卖点”和“早期均线定义不能替代后期严格几何”两条红线，而且很难给出不依赖事后最优周期的失效规则。

更合理的组合顺序是：

1. 缠论引擎先确认标准中枢和 B3/S3。
2. 在同一个确认 K 线，只读取此前及当前可用的 MACD DIFF/DEA。
3. B3 只在两线连续站在正缓冲上方时允许开多；S3 只在两线连续位于负缓冲下方时允许开空。
4. MACD 不改变 B3/S3 对象，不补发新三类点，也不参与退出结构定义。
5. 与不带过滤的原策略并行回测，判断过滤带来的收益、回撤和样本量变化。

## 本次形成的策略与待验证项

- `third_point_migration_macd_regime`：在所有合格迁移 B3/S3 上做 MACD 方向门控。
- `first_centre_B3_macd_regime`：只消费方向周期首个 B3/S3，再做相同 MACD 门控。

二者默认 MACD 参数为 12/26/9，零轴缓冲为 0 tick，空头连续确认 1 根，多头重新站稳连续确认 2 根；最低观察周期必须与数据集周期一致并留在 run 参数中。默认值不是已经证明最优的参数。

同数据补跑已完成，说明“是否形成策略”的工程链路成立，但还不能称为上线候选。下一步至少需要：比较基准/过滤版同一结构信号的逐笔保留率；按市场阶段和多品种归因；做缓冲与确认根数的样本外稳健性；确认减少的亏损是否超过漏掉盈利交易的机会损失。当前只有迁移 MACD 版显示风险调整指标改善，首中枢 MACD 版反而转亏。
