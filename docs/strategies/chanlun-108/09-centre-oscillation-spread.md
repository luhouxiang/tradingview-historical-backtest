# 中枢震荡差价

## 身份与出处

- 运行 ID：`centre_oscillation_spread`，版本 `1.1.0`。
- 理论母项：`ALG-STR-004`；Zn 为辅助量，不是结构信号。
- 出处：[第24课](https://chanlun108.cn/chanzhongshuochan108ke/24.html)、[第33课](https://chanlun108.cn/chanzhongshuochan108ke/33.html)、[第38课](https://chanlun108.cn/chanzhongshuochan108ke/38.html)、[第39课](https://chanlun108.cn/chanzhongshuochan108ke/39.html)、[第45课](https://chanlun108.cn/chanzhongshuochan108ke/45.html)、[第49课](https://chanlun108.cn/chanzhongshuochan108ke/49.html)、[第92课](https://chanlun108.cn/chanzhongshuochan108ke/92.html)。

## 当前算法

1. 只在已确认活动中枢内部工作，且尚未出现标准 B3/S3 或升级/离开信号。
2. 比较中枢内部相邻、同方向、已完成的组成线段；结构固定后以 MACD 同向面积确认盘整背驰。
3. 向下段底背驰开多，向上段顶背驰开空；多空可独立关闭。
4. 用 `Zn` 相对中轴 `Z` 和边界的位置选择强/中/弱手数。Zn 只影响仓位和风险过滤，越过 A/B 不能直接确认三类点。
5. 中枢宽度必须覆盖显式往返成本和最小净空间；弱侧越界且没有快速执行能力时过滤；单中枢进场次数受上限约束。
6. B3/S3、中枢离开、九构件升级风险或来源修订出现时停止震荡、平仓并发布趋势移交，而不复制趋势策略。

## 可能命中的条件

程序易在宽度稳定、往返频繁、边界附近力度衰减的中枢中命中。较有利的是震荡空间显著大于成本且回归速度稳定；较差的是窄幅噪声、单边突破、波动突然扩张或确认后剩余空间很小。

## 优点

- 结构、力度、成本、仓位和停止条件分层清楚。
- 能利用趋势策略通常忽略的中枢内波动。
- B3/S3 出现后明确移交，避免继续逆趋势做差价。

## 缺点与风险

- 高频换手使手续费、滑点和成交能力成为主要风险。
- 中枢内背驰确认有延迟，实际成交常远离理论边界。
- Zn 三档仓位与执行能力参数需要市场级校准。
- 单级别活动中枢发生 revision 时可能频繁重置。
