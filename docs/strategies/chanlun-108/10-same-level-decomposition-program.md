# 同级别分解机械程序

## 身份与出处

- 运行 ID：`same_level_decomposition_program`，版本 `1.1.0`。
- 理论母项：`ALG-STR-005`。
- 出处：[第38课](https://chanlun108.cn/chanzhongshuochan108ke/38.html)、[第39课](https://chanlun108.cn/chanzhongshuochan108ke/39.html)、[第40课](https://chanlun108.cn/chanzhongshuochan108ke/40.html)、[第45课](https://chanlun108.cn/chanzhongshuochan108ke/45.html)，对应同级别分解、结合律、机械操作和按级别持有。

## 当前算法

1. 以 Python 已确认线段为规范分解单元，要求首尾连续、方向交替，并按首次因果确认顺序形成 `A1,A2,...`；不对终态历史重新选择最有利划分。
2. 运行前固定 `odd_direction_is_down`，由此确定奇偶段的操作方向。
3. 比较同方向的 `Ai` 与 `Ai+2`：后段未严格创新方向极值（等号也算未创新）或确认盘整背驰时执行反向操作；创新极值且无背驰则继续持有。
4. `Ai+3` 严格穿过 `Ai` 方向极值时等待新同级结构；未穿过（含等号）时继续围绕原中枢。
5. 来源 revision 会平仓、清链并从修订时点重建。九构件兼容中枢只发布提升候选；只有权威 `level_center.confirmed=true` 且父级/来源关系合法时才正式 `promote_level`、平仓并迁移操作级别。

## 可能命中的条件

程序需要至少形成可比的同级完成段序列，因而在波段清晰、段间交替稳定的行情中更容易命中。若走势很短、线段不断修订，或很快形成高级别中心提升，低级别实例可能只有极少交易。

## 优点

- 把同级别分解机械化，避免事后多义划分挑选最好结果。
- 等号、未完成段、来源修订和级别提升都有显式处理。
- 已接入真正的结构级别提升对象，不以 K 线周期冒充级别。

## 缺点与风险

- 对线段确认和 revision 极其敏感，早期链变化会导致重置。
- 固定奇偶方向是运行参数，错误配置会系统性翻转交易含义。
- 提升前可用样本可能很短；跨层迁移后的绩效需要单独归因。
- 同级“不创新”不等于必然反转，窄幅噪声会产生成本。

## 当前证据

最近 AOL9 为 5 笔，总收益 -0.0330%，胜率 20%，最大回撤 0.0772%，利润因子 0.2217。样本在早期结构链和提升候选附近就限制了低级别运行，5 笔不足以评估长期程序质量。
