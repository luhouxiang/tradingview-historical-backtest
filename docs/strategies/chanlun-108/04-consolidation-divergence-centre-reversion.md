# 盘整背驰中枢回归

## 身份与出处

- 运行 ID：`consolidation_divergence_centre_reversion`，版本 `1.3.0`。
- 理论母项：`ALG-SIG-002`，证据等级 `DERIVED`。
- 出处：[第24课](https://chanlun108.cn/chanzhongshuochan108ke/24.html)、[第27课](https://chanlun108.cn/chanzhongshuochan108ke/27.html)、[第33课](https://chanlun108.cn/chanzhongshuochan108ke/33.html)、[第37课](https://chanlun108.cn/chanzhongshuochan108ke/37.html)、[第39课](https://chanlun108.cn/chanzhongshuochan108ke/39.html)、[第47课](https://chanlun108.cn/chanzhongshuochan108ke/47.html)。第27课区分盘整背驰与至少含两个同级中枢的趋势背驰。

## 当前算法

1. 在同一已确认中枢上下文内，选择方向相同、结构可比且已完成的振荡线段。
2. 结构固定后比较 MACD 同向面积；后段力度减弱时发布类一买/类一卖。它们是盘整背驰转折，不冒充标准 B1/S1。
3. 关联中枢下方的 `class_buy_1` 开多，建立“向上回归中枢”假设；上方 `class_sell_1` 镜像开空。
4. 价格回到关联中枢冻结核心时平仓，完成均值回归。
5. 若尚未回归，却先确认关联中枢的严格 B3/S3，则关闭回归仓并转换到三类点方向；该分支表示盘整假设转成趋势离开。

## 可能命中的条件

程序易在活动中枢上下反复震荡、离开力度逐次衰减时命中。较有利的是核心宽度足够覆盖成本、离开后经常回归；不利的是中枢突然升级、单边突破，或类一信号确认时价格已接近回归目标。

## 优点

- 明确区分“回中枢”和“转三类点”两个互斥结局。
- 采用相同方向的完成结构比较，避免任意 MACD 金叉死叉交易。
- 信号较多，便于研究盘整环境和成本敏感性。

## 缺点与风险

- 均值回归在趋势启动时容易逆势；转换确认前可能积累损失。
- 入场与目标之间的剩余空间可能被确认延迟、手续费和滑点吞噬。
- 当前仓位和退出规则较机械，未按波动或中枢宽度归一化。
- 类一买卖是派生信号，不能与标准趋势一类点混合统计。
