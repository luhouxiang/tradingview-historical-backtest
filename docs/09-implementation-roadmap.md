## 里程碑 10：缠论 108 算法集扩展

按 `docs/15-chan-segment-strategy-milestones.md` 的 10A、10B……子里程碑顺序推进，每次只实现并验收一个子里程碑。算法来源与边界以 `docs/chanlun_108_algorithm_set_20260819` 的 `FORMAL`/`DERIVED` 规格和不变量为依据；与既有项目口径冲突时先记录新决策并提升算法版本，禁止静默复用旧缓存。

共同验收：

- Python 是唯一权威算法实现，策略只消费前一层已确认事件。

- Go 继续只编排任务和读取范围结果，Vue 继续只投影和批量绘制语义对象。
- 算法或策略可从目录发现，结果可在主图和对象树展示，回放/回测不出现未来信息。

当前已完成至 10AB：10Z 已完成 `ALG-SIG-001` 的 B1/S1 候选、确认和失效 revision；10AA 完成 `ALG-STR-005 promote_level`；10AB 在不修改原 13 策略语义的前提下，新增两个 `ALG-STR-003 + ALG-AUX-002` 组合研究策略，并为 13 个基础策略建立逐项课程出处与算法说明。组合策略只允许 MACD 过滤已确认标准 B3/S3，不允许指标制造结构或补发历史机会。九组件 `segment_zhongshu` 仍只发布候选并继续 L0 操作，只有 10Y 结构图的已确认 `level_center` 才触发正式提升。自动化审计仍为 14 项完整实现、11 项固定级别投影、0 项部分实现、2 项延期；新增项是既有目录能力的组合，不改变 27 项覆盖统计。`ALG-STR-006` 区间套与 `ALG-STR-010` 核心/机动双账本继续明确延期。

## 里程碑 12：单周期可靠性研究证据链

继续坚持一次只实现一个子里程碑，并明确不引入第二个 K 线周期。

- 12A 已完成：本地历史批量导入；导入与图表显示窗口解耦；数据集精确交易日覆盖、`independence_group`、同组重叠区间和 504 日/3 独立组研究门禁；回测权益保存交易日，生成 `daily_returns.parquet`，以日收益计算可解释的年化收益、波动率和 Sharpe。当前原始 YL9/AOL9 已有多年数据潜力，但只有两个长样本独立品种组，因此仍为探索级。
- 12B 已完成：固定策略版本与规范化参数在 1–32 个同周期 `dataset_id + data_revision` 上分别生成正式子 run；单数据集允许完成走步、压力和统计探索，但不能满足可靠候选的独立组门槛。Research Study 保存稳定签名、完整数据版本、执行/成本、资金、种子与子 run 引用，并以临时目录原子提交和 `_SUCCESS` 保证完成结果不可覆盖。多数据集日收益先在同一 `independence_group` 内等权，再在独立组间等权，AO2609/AOL9 等相关样本不会重复增加认证权重；聚合提供最差数据集、收益中位数、盈利比例、成交数和最大回撤。Go 提供创建、轮询、取消、journal 恢复、列表、详情和结果 API，Vue 提供同周期选择、固定参数、证据摘要和历史恢复。
- 12C 已完成：Research Study 可选默认 252/63/63 交易日滚动走步；折边界由权威 `trading_day` 生成且验证窗口不重叠。每个候选只用当前训练窗指标排名和硬约束筛选，选中后才创建唯一验证 run；所有折均从数据集起点推进权威指标/缠论因果状态，仅在折内执行与计分。完成事实保存每折训练排名、选中参数、训练与样本外指标、正式子 run、参数漂移和稳定失败原因；跨数据集样本外日收益继续按独立组内、组间两级等权，持久化为 Parquet，并汇总盈利折比例、最差折回撤、样本外成交数和独立组等权参数稳定度。
- 12D 已完成：冻结每个走步折在训练窗选中的参数，并在原验证窗分别创建基准、1.5 倍成本、2 倍成本、额外 1/2 tick 滑点、额外延迟一根 K 线和成交量参与率 10% 的不可变正式子 run，压力场景绝不重新选参。成本倍数真实作用于佣金和基础滑点，额外 tick 与延迟进入逐 K 线执行；参与率采用当根成交量上限的 IOC 部分成交，零容量拒单，未成交余量不虚构成交。研究结果按独立组等权汇总场景收益、回撤、成交率和相对基准的边际退化，标记首个非正收益场景；场景参数、成交模式、子 run 和详细结果均进入 manifest/原子提交 artifact，Vue 提供压力场景表和失败原因。
- 12E 已完成：只用独立组等权的样本外日收益执行固定种子、5 日非循环移动区块 bootstrap（默认 2,000 次），生成总收益、日均收益/期望值和最大回撤的 95% 置信区间；记录全部尝试参数组合，并对实际入选候选的样本外比较执行 Holm 校正和多重比较警告。数值参数按声明候选值的相邻档位冻结扰动，按独立组等权计算核心门禁通过率。Python 权威输出探索性/研究候选/可靠候选三级认证、证据矩阵和历史研究免责声明，Vue 展示走步、压力、置信区间、邻域和未通过原因。Go 校验统计配置、不可变统计 artifact、取消与恢复边界，并避免把 Python 原子写临时文件误作可恢复目录。

  真实 5 分钟验收使用 `DCE.YL9.5m`（58,812 根、861 个交易日）和 `SHFE.AOL9.5m`（69,289 根、756 个交易日），完成 17 个走步折、51 个训练 run、17 个验证 run、119 个压力 run、17 个邻域 run及 2,000 次 bootstrap；中断后以同一 Study journal 恢复并复用已完成子 run。结果正确判为“探索性”：只有 2 个独立品种组且样本外无已平仓交易，未越级显示“可靠候选”。可重复验收摘要保存于 `trading-data/acceptance/milestone12-real-e2e.json`，原始历史文件未修改，也未生成替代原始数据。

  12E 修改了 Research Study OpenAPI/Schema 的统计配置、统计证据、认证和邻域子 run 契约；Python、Go、Vue、契约测试及真实数据 E2E 覆盖对应验收项。已知限制是当前本地样本只有两个独立组，因而不能满足可靠候选的三组门槛；“可靠候选”始终只表示历史研究门禁通过，不保证未来盈利。
