# 09 Codex 分阶段实施路线

总原则：一次只完成一个里程碑。每个里程碑通过验收后才进入下一个。

## 里程碑 0：工程骨架与契约

生成：

- Go 1.25.7 工程、配置、健康检查、错误模型、路径保护和日志。
- Python 3.14 工程、内部健康检查、任务占位和日志。
- Vue 3 + TypeScript + Vite 外壳、布局框架、API 客户端和日志队列。
- OpenAPI/Schema 校验、类型生成脚本。
- 启动、构建、测试和 VS Code 调试配置。

验收：

- 三端可独立启动。
- Go 健康检查显示 Python 状态。
- Vue 显示空的 TradingView 风格框架。
- 三端日志含真实源文件和行号并能轮转。
- 所有契约示例校验。

不做：真实数据、图表、指标、回测。

## 里程碑 1：历史数据目录与导入

实现：

- history 扫描。
- tdx_txt_v1 适配器。
- 编码、标题、字段识别。
- 交易日历与夜盘转换。
- 质量报告。
- data_revision、Parquet、catalog 和原子完成。
- 数据集列表和元数据 UI。

验收：docs/08 第 2–4 节。

## 里程碑 2：K 线与多窗格

实现：

- K 线范围 API。
- 前端尾部加载、缓存、向左预取和 generation_id。
- 单一 ChartGroup 多 pane。
- 默认 6:1:1、共享时间轴、十字线和可拖分隔线。
- 右侧/底部面板压缩布局。
- 成交量副图。

验收：

- 3000/1500 加载规则。
- 缩放和调整尺寸不调用 Python。
- 时间轴、价格轴和分隔线行为正确。

## 里程碑 3：普通指标

实现：

- 算法定义和参数 Schema。
- Go 任务管理、Python 计算、Parquet 缓存。
- MA、MACD、ATR。
- 主图/副图添加、删除和参数编辑。
- 对象树的 SeriesSource。

验收：

- 缓存键与失效测试。
- 黄金指标测试。
- UI 按范围查询，不随缩放重算。

## 里程碑 4：绘图、图层与工作区

实现：

- LayerManager。
- 趋势线、水平线、矩形、文字、测量。
- 命中检测、控制点、磁吸、锁定、隐藏。
- 撤销/重做。
- 对象树排序。
- 布局和绘图原子保存、revision 冲突。

验收：docs/04 第 15 节相关项。

## 里程碑 5：缠论

实现：

- 包含关系、分型、笔、中枢；按 C-015 不实现线段。
- 结构对象 Parquet。
- 因果事件流。
- 检查点。
- 批量 ChanPrimitive。
- 未确认/确认样式。

验收：

- 前缀不变性。
- 检查点恢复一致。
- 10,000 对象性能。
- 对象树只显示策略组和类别，不创建海量 Vue 节点。

## 里程碑 6：回放

实现：

- replay 任务与缓存。
- replay_cursor、单步、速度、暂停、跳转。
- 按 known_at 显示、修改和撤销图形。
- 阶段信号和策略状态的数据窗口。

验收：

- 未来 K 线和未来事件不可见。
- 游标移动不调用 Python。
- 后退后状态恢复一致。

## 里程碑 7：策略与回测

实现：

- 标准策略接口。
- MA20 反抽失败做空示例。
- 订单、成交、持仓、权益。
- 手续费、滑点、保证金。
- run 不可变目录、汇总和明细 API。
- 底部回测、交易、权益面板。

验收：

- 回放/回测信号一致。
- 默认下一根开盘成交。
- 相同输入可复现。
- 成功 run 不可覆盖。

## 里程碑 8：强化与发布

实现：

- 性能基准与剖析。
- 错误恢复、取消、重启后 interrupted。
- 完整 E2E。
- 文档、安装和示例。
- 缓存清理命令及安全保护。

验收：docs/08 总体验收清单。

## 里程碑 9：参数优化接口

首期系统全部稳定后再做：

- SearchSpace、Objective、Constraint、Study。
- Grid 和 seeded random。
- 训练/验证区间。
- 结果比较与稳定性报告。

本里程碑仍不实现 AI 自动调参，只提供未来可调用的标准接口。

## 实时阶段

实时行情、WebSocket、实盘订单另立项目版本和 ADR。不得在上述里程碑中夹带。
