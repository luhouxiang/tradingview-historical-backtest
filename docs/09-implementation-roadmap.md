# 09 Codex 分阶段实施路线

总原则：一次只完成一个里程碑。每个里程碑通过验收后才进入下一个。

## 里程碑 0：工程骨架与契约

生成：

- Go 1.25.7 工程、配置、健康检查、错误模型、路径保护和日志。
- Python 3.14 工程、内部健康检查、任务占位和日志。
- Vue 3 + TypeScript + Vite 外壳、布局框架、API 客户端和日志队列。
- OpenAPI/Schema 校验、类型生成脚本。
- 启动、构建、测试和 VS Code 调试配置。

验收：

- 三端可独立启动。
- Go 健康检查显示 Python 状态。
- Vue 显示空的 TradingView 风格框架。
- 三端日志含真实源文件和行号并能轮转。
- 所有契约示例校验。

不做：真实数据、图表、指标、回测。

## 里程碑 10：缠论 108 算法集扩展

按 `docs/15-chan-segment-strategy-milestones.md` 的 10A、10B……子里程碑顺序推进，每次只实现并验收一个子里程碑。算法来源与边界以 `docs/chanlun_108_algorithm_set_20260819` 的 `FORMAL`/`DERIVED` 规格和不变量为依据；与既有项目口径冲突时先记录新决策并提升算法版本，禁止静默复用旧缓存。

共同验收：

- Python 是唯一权威算法实现，策略只消费前一层已确认事件。
- 正例、反例、等号、未完成和事件时点测试通过。
- Go 继续只编排任务和读取范围结果，Vue 继续只投影和批量绘制语义对象。
- 算法或策略可从目录发现，结果可在主图和对象树展示，回放/回测不出现未来信息。

当前已完成至 10AA：10Z 已完成 `ALG-SIG-001` 的 B1/S1 候选、确认和失效 revision；10AA 又完成 `ALG-STR-005 promote_level`。九组件 `segment_zhongshu` 只发布候选并继续 L0 操作，只有 10Y 结构图的已确认 `level_center` 才触发平仓、从 L0 迁移到 L1、清空旧序列并等待新同级序列；确认来源修订时因果重置。该提升完全基于同一数据集的结构级别，不读取或拼接其他 K 线周期。自动化审计为 14 项完整实现、11 项固定级别投影、0 项部分实现、2 项延期。按当前忽略多周期/递归多级别的范围，既有固定级别算法保持可测试、可回放、可上图；`ALG-STR-006` 区间套与 `ALG-STR-010` 核心/机动双账本明确延期，不以固定线段投影冒充完成。

## 里程碑 11：缠论策略比较与研究工作台

按 11A、11B、11C、11D 顺序逐项实施和验收。

- 11A 已完成：算法目录发布研究分类元数据；默认发现 13 个正式策略；comparison 固定数据 revision、完整参数与统一执行口径；Go 校验、编排、取消并隔离单策略失败；Python 顺序执行且批次内只计算一次权威缠论结构；成功子项生成正式 run；比较结果原子保存；Vue 提供一键全跑、策略选择、参数覆盖、公共资金/成本/风控和实时进度。
- 11B 待实施：完整排行榜、结果分层、收益—回撤 Pareto 前沿、散点图和历史研究恢复增强。
- 11C 待实施：单策略交易/权益/回撤拆解、2–5 策略曲线与主图事件叠加。
- 11D 待实施：以开仓信号可用时点重建缠论行情条件、交易归因、热力图和反向定位。

11A 不生成主观综合分，也不把延期策略伪装为可运行策略。多数据集联合研究、实时行情、模拟柜台和实盘下单不属于本里程碑。
