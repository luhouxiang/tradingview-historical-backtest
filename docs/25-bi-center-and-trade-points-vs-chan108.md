# 笔中枢、线段中枢与 108 课买卖点差异说明

日期：2026-09-25。适用算法：`chan_engineering@18.0.0`，中枢规则：`local_center_boundary_v1`。

## 1. 先给结论

1. 当前“笔中枢”是三个连续已确认笔的区间交集，是为了显示和审计而固定的一种工程局部分解；它不是 108 课所定义的“由三个连续、已完成的次级别走势类型重叠形成的本级别中枢”。
2. 当前标准/类买卖点并不消费笔中枢。Python 先把 `unit_kind=SEGMENT` 的 `local_center` 投影成信号中枢，再用已确认线段、线段中枢和 MACD 柱面积计算背驰与买卖点。勾选“笔中枢”只改变显示，不改变买卖点。
3. 因此，把图上的笔中枢框与买卖点直接对照，天然可能看不出课文图中的“围绕同一中枢的离开与回试”。两者目前不是同一计算层。
4. 当前算法是单周期、固定线段层的因果工程 profile，不是 108 课的递归级别体系。它不实现区间套，也不把一个线段自动证明为某个严格次级别完整走势类型。

## 2. 108 课中的中枢基础

本项目固定引用的课程口径来自第 18、20、33、35、37、53、54、67、71、78、101 课：

- 中枢由三个连续、已完成的次级别走势类型重叠形成，不是简单由任意三笔重叠形成。
- 初始三个走势确定核心 `ZD/ZG`；延伸、离开、中枢破坏和高级别重组不能只用一个滚动三单元交集代替。
- 连接走势和中枢内部构件不必与观察级别相同；`a+B+b` 可按结合律出现多义分解。
- 买卖点是走势结构中的位置：一类点依赖趋势背驰，二类点依赖一类点后的首次次级别回试，三类点依赖离开中枢后的首次次级别回试不回到中枢。

所以，课程里的“中枢级别”来自递归走势结构，不等于 K 线周期，也不等于把 BI 或 SEGMENT 作为下拉显示模式。

## 3. 当前笔中枢怎样计算

BI 流与 SEGMENT 流分别运行同一个局部状态机。对笔中枢，单元就是已确认笔；从 `scan_floor` 起按时间检查最早的连续三笔：

```text
ZD = max(low(Bi), low(Bi+1), low(Bi+2))
ZG = min(high(Bi), high(Bi+1), high(Bi+2))
成立条件：三笔均已确认，并且 ZD < ZG
```

形成后冻结 `ZD/ZG`，不对每个滚动三笔再建框。向上离开要求上升笔终点高于 `ZG`，其紧邻下降笔的完整最低价严格高于 `ZG` 才确认分界；向下镜像。确认后从首次回试笔开始寻找下一个最早三笔交集。

这些规则中的“最早种子优先、只允许正宽度交集、紧邻反向单元严格分离、确认后不复用旧种子、固定矩形横向边界”都是软件新增规则，不是 108 课唯一分解。

主要差异：

| 项目 | 108 课结构口径 | 当前笔中枢 |
|---|---|---|
| 构件 | 三个连续完成的次级别走势类型 | 三个连续已确认笔 |
| 级别 | 由递归走势关系确定 | 固定标为 `BI/stroke` |
| 多义性 | 允许结合律下的合理多种分解 | 固定最早种子优先，输出单一局部分解 |
| 点中枢 | 课程例子允许单价位重合 | 当前要求 `ZD < ZG`，排除 `ZD == ZG` |
| 离开/回试 | 要求相应次级别走势完成并结合上下文 | 用紧邻反向笔做局部确认 |
| 高级别 | 可由完整次级别走势递归形成 | 15F 已删除旧递归高级别图，不作该宣称 |

因此，“笔中枢”适合观察三笔重叠、进入笔、离开笔和首次回试笔，不适合直接当作课文标准中枢去验证标准一二三类点。

## 4. 当前买卖点的实际计算依据

### 4.1 公共前提

所有买卖点使用已确认线段及 `unit_kind=SEGMENT` 的局部中枢。笔中枢不参与买卖点计算。信号默认在结构对象可知后发布，回测默认下一根 K 线开盘成交；图上的结构端点、确认竖线和成交标记可能是三个不同位置。

### 4.2 一类买卖点

当前标准一买/一卖要求：

1. 至少有两个时间分离的线段中枢；两者完整外围区间也分离，由此判定上涨或下跌趋势方向。
2. 前中枢离开线段 `b` 与后中枢离开线段 `c` 同方向，`c` 还要顺趋势创新极值。
3. 用同方向 MACD 柱绝对面积比较，要求 `area(c) < area(b)`。
4. `c` 完成时先发布候选；其后一条反向线段确认下层转折后，才把相同端点修订为已确认 B1/S1。

与 108 课的差异在于：MACD 同号柱面积是固定工程力度 profile；当前没有递归证明 `b/c` 内部所有次级别资格，也额外等待完整反向线段确认。因此信号常在理论端点之后很久才“已知”，价格也可能已经反弹/回落一段。

### 4.3 二类买卖点

当前二买/二卖只能从已经存在的一类点或“类一”起点派生。算法固定取一类点结束线段之后的第二条线段作为首次同向回试结果：

- 二买要求该线段向下；二卖要求该线段向上。
- 与三类点同端点重合：`strongest`。
- 二买低点不低于一买、或二卖高点不高于一卖：`normal`。
- 若产生了更不利的新极值，只有该线段自身存在已确认盘整背驰时才标为 `weakest`；否则不产生二类点。

当前缺少第 53 课所述“本级别没有标准一类点时，由小转大等下层结构形成二类点”的入口。因此它只是“已有一类点后首次回试”的子集，而不是 108 课全部二类点。

### 4.4 三类买卖点

当前三买要求线段中枢已向上离开，紧随离开线段的第一条已完成向下线段最低价不低于 `ZG`；三卖镜像，高点不高于 `ZD`。信号保存来源中枢、离开线段、首次回试线段、边界关系与确认时间。

但生产中枢本身使用更严格的局部分界状态机：回试触及 `ZG/ZD` 会让离开候选失效，只有严格在核心外才关闭中枢。因此虽然信号函数标记为闭区间 `lesson20_inclusive_v1`，实际进入该函数的已关闭中枢通常已经受上游严格分离约束。这个组合比课文某些“触边不破”示例更严格，会漏掉或推迟边界等号处的三类点。

### 4.5 “类一/类二/类三”

项目把盘整背驰转成 `class_buy_1/class_sell_1`，再沿同样的回试规则派生类二，并在后续标准三类点之前保留类三生命周期标记。这是项目的工程分类，不等于 108 课新增了一套标准“类一、类二、类三”。把它们与课文标准点混画，是视觉差异的另一个来源。

## 5. 为什么会与 108 课示例图差很多

按影响从大到小：

1. **对错了中枢层**：图上看的是笔中枢，买卖点算的是线段中枢。
2. **标准中枢被局部中枢替代**：线段中枢仍是三个 SEGMENT 单元的固定局部分解，没有递归证明它们是目标级别的三个完整次级别走势类型。
3. **确认延迟**：笔、线段、背驰和一类点都必须因果确认；标记锚在结构端点，但 `known_at_bar_index` 可能晚很多。
4. **力度公式固定**：一类点只使用同方向 MACD 柱面积收缩和新极值，不覆盖课程允许讨论的所有力度比较。
5. **二类点入口不完整**：只实现已有一类点后的回试子集，缺少“小转大/无本级一类点”分支。
6. **三类点边界偏严**：上游局部中心用严格不触边分离，课程图中某些等号边界会被算法当作回到中枢。
7. **点中枢缺失**：`ZD == ZG` 不建当前局部中枢，而 108 课存在点中枢解释。
8. **固定单一分解**：课程允许结合律和多义分解；软件只保留最早种子优先的一条路径。
9. **类点混画**：盘整背驰派生的类点与标准点同时显示时，很容易误以为都是课文标准买卖点。

## 6. 正确的核对方法

不能只截取买卖点附近几十根 K 线看形似。每个点应同时导出：

- 信号类别：标准或类；
- 实际计算层：当前固定为 SEGMENT；
- 来源中枢 ID、三条种子线段、`ZD/ZG`、外围 `DD/GG`；
- 离开线段、首次回试线段、比较线段 `b/c`；
- MACD 两段面积、新极值结果；
- 结构端点 K、`known_at_bar_index`、回测成交 K；
- 若是二类点，来源一类点及 strongest/normal/weakest 分支；
- 若是三类点，回试序号、边界 profile 和到核心/外围的距离。

只有这些事实与课文图中的层级、走势分解和确认时点一致，才可以说是在比较同一种买卖点。

## 7. 当前能力边界

15F 的目标是消除旧高级别中枢伪递归和显示歧义，不是补完 108 课递归级别体系。现在的结果更诚实：笔中枢与线段中枢可独立显示，标准买卖点明确只来自线段层；旧高级别中心和依赖其升级分支的策略已经撤下。若下一步追求与 108 课示例更一致，应先做“完整次级别走势类型与递归中枢”的新算法里程碑，再重新定义标准买卖点，不能让 Vue 或策略层把三笔重叠改名冒充标准中枢。
