# 05 策略目录

本目录把讨论中提到的方法写成策略级规范。所有策略均先满足
`03_center_detection.md` 与 `04_signal_rules.md`，再叠加指标、仓位和执行。

## 1. `downtrend_reversal_only`

用途：中小资金只参与“下跌＋上涨”，回避同级盘整耗时。

前置：

- 固定操作级别；
- 之前已形成“下跌＋盘整＋下跌”；
- 第二段下跌出现确认趋势底背驰与B1。

入场：B1确认后，最早在 `confirmed_at` 可执行价介入。

持有/退出：

- 若直接演化为同级上涨，持有至同级卖点或趋势背驰；
- 若演化为同级盘整，利用次级别S1减仓/退出；
- 不为等待盘整后的方向而长期占用资金。

失效：前置只有一个中枢或B1只是盘整背驰。

## 2. `fixed_level_centre_decision_tree`

用途：第49课式固定级别完整决策树。

流程：先固定级别，再找当下之前最近一个该级别中枢。

| 位置 | 三买卖点状态 | 操作 |
|---|---|---|
| 中枢内 | 中枢延伸 | 初学者等待；熟练者仅做低级别信号 |
| 中枢下 | 尚无S3 | 比较最近两次向下震荡力度，衰减后区间套找买点 |
| 中枢下 | 已有S3 | 不做同级多头，等待下跌走势完成 |
| 中枢上 | 尚无B3 | 等待第一次完整回试 |
| 中枢上 | 已有B3 | 若离B3近可介入；过远则等新中枢/新机会 |

关键：策略目标是结构响应，不是预测中枢接下来向上还是向下。

## 3. `centre_oscillation_swing`

用途：已确认中枢内的低级别差价。

前置：

- 当前中枢 `active`；
- 尚无B3/S3；
- 有至少两次同方向震荡段可比较；
- 操作者允许使用比目标级别更低的执行级别。

买侧：当前向下段相对最近前一向下段力度衰减，形成盘整底背驰，再在段内
用区间套确认低级别B1。

卖侧：当前向上段相对最近前一向上段力度衰减，形成盘整顶背驰，再确认
低级别S1。

停止条件：

- B3后停止卖出同级上移仓位；
- S3后停止向下回补；
- 中枢升级后切换到新级别；
- 数据或完成结构不足时不交易。

禁止：仅因为价格到 `ZD/ZG` 就机械买卖。

## 4. `third_buy_centre_migration_hold`

用途：B3确认后的中枢上移持有。

入场：标准B3确认，或已有仓位继续持有。

持有：

- 新同级中枢形成之前，把小级别回调视为上移过程内部波动；
- 不在同级中枢上移中继续做同级短差；
- 新中枢形成后切换为中枢震荡策略。

退出：中枢完成后的向上移动出现同级趋势背驰，退出对应级别仓位。

风险：B3后也可能扩展成更高级别盘整，因此监视后续盘整背驰和新中枢。

## 5. `first_centre_B3_rotation`

用途：有充足时间的小资金轮动。

前置：

- 固定一个可响应级别；
- 只做该级别B3；
- 尽量只做上涨第一个中枢之后的B3。

管理：

1. B3确认后介入；
2. 下一次级别向上走势不能创新高或出现盘整背驰，退出；
3. 若进入新一轮中枢上移，持有至上移背驰；
4. 背驰时至少减半；随后次级别反抽不能创新高或出现盘整背驰时清仓。

避免：第二个及以后中枢的B3形成更大级别中枢的概率提高，必须降权或过滤。

## 6. `multi_timeframe_core_plus_swing`

用途：大级别核心仓位＋次级别短差。

规则：

- 大级别B1/B2/B3建立或维持核心方向；
- 次级别S1减仓；
- 次级别B1回补；
- 大级别卖点未出现前，不改变核心方向；
- 所有跨级别事件都保存各自 `analysis_level`，不得把次级卖点升级为大级卖点。

容量、手续费和滑点必须进入策略参数；否则频繁次级操作可能没有净优势。

## 7. `trend_divergence_reversal`

用途：标准趋势背驰及B1/S1。

前置：

- 至少两个同级非重叠中枢；
- 最后趋势段创新高/低；
- 结构力度衰减；
- MACD等只作辅助；
- 低级别完成确认。

入场/退出：按B1/S1确认事件操作，而非MACD交叉本身。

后续分支：最后中枢扩展、更高级盘整、反趋势。策略必须继续观察B2/B3，
不能假定V形反转。

## 8. `consolidation_divergence_centre_reversion`

用途：一个中枢内/旁的盘整背驰回归。

规则：

- 比较 `a+Z+c` 中同向的 `a/c`，或同一中枢相邻同向震荡段；
- `c` 力度衰减后，在 `c` 内找低级别结束点；
- 预期首先是回中枢，不是新趋势；
- 若第一次反向回试不回中枢，立即切换B3/S3逻辑。

特别警告：向下离开后的盘整底背驰若反弹不能进入中枢，会形成S3，不能
继续执行“底背驰买入回中枢”的假设。

## 9. `small_to_large_B2`

用途：目标级别缺少标准B1的小转大转折确认。

规则：

- 小级别背驰先触发目标级别转折候选；
- 等目标级别第一次反向走势和回试完成；
- 用B2/S2确认目标级别可交易点；
- 信号标签固定为 `small_to_large_B2/S2`；
- 不能与有标准B1/S1的普通二买二卖混合评估。

## 10. `accelerated_breakout_lower_level_B3`

用途：大级别中枢猛烈突破时，用较小级别B3提前介入。

前置：

- 大级别中枢已确认；
- 离开快速、猛烈，明显不同于普通震荡；
- 成交量和走势力度配合；
- 低级别B3已完整确认；
- 策略允许承担早于大级别B3的额外错误风险。

缺任一前置时，等待与大中枢匹配的标准B3。成交量不能单独制造三买。

## 12. 策略共同接口

所有策略建议暴露：

```text
on_structure_event(event)
on_indicator_snapshot(snapshot)
on_execution_update(fill_or_reject)
current_intent() -> enter | add | reduce | exit | hold | wait
explain() -> structural_evidence + auxiliary_evidence + invalidation
```

策略不得直接读取未来完成对象；只能消费按时间发布的事件。
