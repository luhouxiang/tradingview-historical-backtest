## 恢复边界

平台未提供这一时间段的逐字会话导出。本包因此采用两层保存：

- `source/recovered_discussion.md`：只保留当前线程中可恢复的实质性内容，
  并用“重构摘要”标记非逐字部分；
- `docs/` 与 `specs/`：把讨论中的结论转写成可执行规范。

不得把 `source/recovered_discussion.md` 当作法律、审计或逐字引用用途的
原始聊天日志。它适合帮助 Codex 理解项目缘起、术语和决策。

## 三种权威等级

| 标记 | 含义 | Codex 应对 |
|---|---|---|
| 原文定义 | 讨论引用的课文定义或定理 | 保留课次与适用级别，不擅自改写成指标信号 |
| 项目硬规则 | 本次讨论为程序一致性选定的口径 | 实现和测试必须遵守 |
| 实现建议 | 事件模型、字段、配置、测试方式 | 可适应宿主仓库，但要说明差异 |
