# 07 事件状态机、回测与无未来函数约束

## 1. 推荐管线

```text
market data
→ bar normalisation / inclusion handling
→ fractal events
→ stroke events
→ segment candidate/confirmed/invalidated events
→ centre events
→ movement-type events
→ structural signal events
→ auxiliary indicator evidence
→ strategy intent
→ execution model
→ portfolio/risk accounting
```

每一层只消费前一层按时间发布的事件，不能直接访问“最终分解结果”。

## 2. 为什么端点和确认时点必须分开

结构通常在某个历史端点发生，但只有后续低级别反向结构完成后才可知道该
端点成立。例如下跌末端的理论最低点可能在10:00，直到10:15形成低级别
结束确认。回测若在10:00成交，就是未来函数。

建议：

```text
endpoint_time      = 10:00
confirmed_at       = 10:15
signal_price_ticks = 1000
executable price   = first allowed fill at/after 10:15
```

## 3. 候选与确认事件

### 3.1 候选

候选事件可更新：

- 临时端点；
- 临时高低点；
- 暂估MACD面积；
- 当前是否仍可能满足背驰；
- 失效原因。

策略默认不得以候选成交。若研究“抢跑策略”，必须单独命名、单独回测并承担
重绘风险，不能与标准确认策略混合。

### 3.2 确认

确认事件不可静默修改。若底层数据修订，发布：

- 新版本确认事件；
- `supersedes_event_id`；
- 修订原因与数据版本。

## 4. MACD面积与未完成末段

错误做法：

```text
完整前段面积 = 100
正在形成的末段面积 = 40
=> 立即确认背驰
```

末段未完成时面积天然偏小。正确做法：

1. 结构进入潜在背驰段，发候选；
2. 随新柱更新临时面积；
3. 若力度超过比较段，候选失效；
4. 若低级别结构确认末段结束且整体条件仍满足，才确认背驰。

## 5. 边界比较

输入价格先变为整数ticks：

```text
price_ticks = round(price / min_tick)
```

实际转换需按交易所精度和Decimal规则实现，不能直接使用二进制浮点
`round`。确认B3/S3：

```text
B3: retest_low_ticks >= ZG_ticks + 1
S3: retest_high_ticks <= ZD_ticks - 1
```

## 6. 回测成交约束

- 成交时点不得早于 `confirmed_at`；
- 同一时间戳内的事件顺序要确定：数据收盘、指标计算、结构确认、策略决策、
  下单、成交；
- 若确认依赖当前K线收盘，默认最早下一可交易tick/下一根K线成交；
- 涨跌停、停牌、无流动性时不得假设成交；
- 手续费、滑点、撮合延迟和合约换月是执行层，不得藏在结构算法中；
- 理论信号价格与实际成交价格同时保存。

## 7. 版本化与可解释性

每个事件保存：

- `rule_version`；
- `data_version`；
- `evidence_ids`；
- `parent_event_ids`；
- 配置快照哈希；
- 失效或拒绝原因。

策略解释至少回答：

1. 当前分析级别是什么？
2. 使用了哪三个/哪些完成组件？
3. 当前中枢边界和状态是什么？
4. 这是结构证据还是指标辅助？
5. 理论端点何时发生，何时确认？
6. 哪个条件会使候选失效？

## 8. 最小测试矩阵

### 中枢

- 三个完成区间有宽度重叠；
- 只在一个tick点重叠；
- 完全无重叠；
- 第三个组件未完成；
- 中枢延伸后核心区不漂移；
- 第九个组件触发升级。

### B3/S3

- 回试低点高于ZG一tick；
- 回试低点等于ZG；
- 回试进入核心；
- 第一次回试失败、第二次不回核心；
- 离开或回试未完成；
- 错误引用较早中枢。

### 背驰/B1

- 两个合法同级非重叠中枢＋末段创新低＋力度衰减；
- 只有一个中枢；
- 两中枢级别不同；
- 末段未创新低；
- 仅MACD背离；
- 未完成末段面积偏小后继续放大并失效。

### B2

- 普通B2；
- B2与B3合一；
- B2低于B1但有盘整背驰；
- B2低于B1且无盘整背驰；
- 小转大B2；
- 回试未完成。

### 时间

- `endpoint_time < confirmed_at`；
- 当前K线收盘确认、下一时点成交；
- 候选失效历史仍可审计；
- 修订数据发布新版本而非覆盖。

## 9. 性能评估必须分层

至少分别报告：

- 结构检测准确性；
- 候选转确认率和平均确认延迟；
- 理论端点价与实际可执行价偏差；
- 各级别、各 `component_kind`；
- B1/B2/B3及强弱子类；
- 毛收益、净收益、滑点敏感性、最大回撤；
- 样本内、样本外与走步验证。

不要用最终静态分解的“识别准确率”替代实时事件回测。
