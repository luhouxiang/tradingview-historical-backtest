目前“研究工具链”已经完成，但还没有自动得出某只票最适合哪个算法。系统现在能让你用统一、可复现的流程筛选和验证候选算法。

当前本地真实验收使用 YL9、AOL9，测试的 `second_buy_only` 样本外为零交易，因此结论只是“探索性”，不是已经找到了可靠盈利策略。

## 推荐使用流程

### 1. 准备目标标的数据

1. 启动 `启动程序.cmd`。
2. 打开右侧“数据集”。
3. 扫描并导入目标标的历史 TXT。
4. 选择目标数据集，核对：
   * 标的和周期。
   * 覆盖时间。
   * `dataset_id` 和 `data_revision`。
   * 最好至少 504 个交易日。

如果只有某只票的一段历史，只能做探索。要评为“可靠候选”，还需要至少三个独立品种组。

### 2. 先筛选适合这只票的算法

打开底部“策略研究”：

1. 选择当前标的数据集。
2. 默认全选 13 个正式策略。
3. 设置真实的：
   * 初始资金。
   * 手续费。
   * 滑点。
   * 合约乘数。
   * 保证金率。
4. 点击“一键回测所选 13 个策略”。
5. 完成后按下面顺序筛选：


| 指标          | 建议                             |
| --------------- | ---------------------------------- |
| 交易数        | 太少先排除，至少先看 20 笔以上   |
| 总收益        | 必须在真实成本后为正             |
| 最大回撤      | 建议不超过 20%                   |
| 期望值        | 应大于 0                         |
| Profit Factor | 应大于 1                         |
| Sharpe        | 越高越好，但需结合样本量         |
| Pareto        | 优先关注高收益、低回撤的前沿策略 |

先保留约 2–4 个候选，不要只选择收益最高的一个。

### 3. 查看胜率和收益明细

当前批量策略表主要显示总收益、回撤、Sharpe、PF、期望和交易数。胜率在底部“回测”的单策略结果中显示。

对候选策略：

1. 记下策略名称和参数。
2. 打开“回测”。
3. 使用相同数据、参数、成本和资金重新运行。
4. 查看：
   * `胜率`
   * `总收益`
   * `年化收益`
   * `最大回撤`
   * `Profit Factor`
   * `每笔期望`
   * 平均盈利/平均亏损
   * 最大连续亏损
   * 交易和权益曲线

指标口径：

* 胜率 = 盈利的已平仓交易数 ÷ 全部已平仓交易数。
* 总收益 = `(期末权益 - 初始权益) ÷ 初始权益`，已计入手续费和滑点。
* 年化收益从每日权益计算，不是把 5 分钟收益直接乘 252。
* 每笔期望 = 所有已平仓交易净盈亏的平均值。

例如“胜率 70%”并不一定好：如果平均赚 100、平均亏 500，仍可能亏钱。因此至少同时看胜率、盈亏比、PF、期望值和回撤。

### 4. 优化候选参数

打开底部“优化”：

1. 每次只优化一个候选策略。
2. 只给少量有经济意义的候选参数。
3. 使用训练—验证拆分。
4. 不建议单独最大化胜率，优先：
   * 最大化总收益或 Sharpe。
   * 同时约束最少交易数和最大回撤。
5. 保留验证集表现稳定、不是只在训练集突出的参数。

不要优化 `checkpoint_interval` 这类工程参数。

### 5. 做正式走步和可靠性验证

在“策略研究”顶部的“单周期可靠性研究”：

1. 固定一个候选策略。
2. 选择至少两个相同周期的数据集。
3. 勾选：
   * “走步样本外验证”
   * “执行与成本压力测试”
   * “统计稳健性与认证”
4. 默认使用：
   * 252 日训练。
   * 63 日验证。
   * 63 日步长。
5. 填写需要选择的参数候选值。
6. 点击“运行研究”。

重点看：

* 样本外收益和成交数。
* 盈利折比例。
* 最差折回撤。
* 参数是否频繁漂移。
* 2 倍成本后是否仍盈利。
* 延迟一根 K 线后是否仍盈利。
* Bootstrap 日均收益 95% 下界是否大于 0。
* 参数邻域通过率是否达到 60%。
* 最终等级是“探索性”“研究候选”还是“可靠候选”。

## 如何判断“某只票适合某算法”

比较合理的判断标准是：

* 目标标的多数样本外折收益为正。
* 样本外交易数足够，而不是几笔偶然交易。
* 样本外每笔期望为正。
* 回撤在可承受范围。
* 参数相邻档位仍有效。
* 真实成本、2 倍成本和延迟后没有立刻失效。
* 其他独立标的上没有完全崩溃。

因此最终结论应写成：

> “算法 A 在标的 X 的 5 分钟历史样本外测试中，完成 N 笔交易，胜率 X%，净收益 Y%，最大回撤 Z%，每笔期望为正；但当前证据等级为某级。”

而不是简单说“这只票适合算法 A”。
