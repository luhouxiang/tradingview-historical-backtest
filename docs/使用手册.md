目前“研究工具链”已经完成，但还没有自动得出某只票最适合哪个算法。系统现在能让你用统一、可复现的流程筛选和验证候选算法。

当前本地真实验收使用 YL9、AOL9。AOL9 的 `second_buy_only` 标准二买模式为零交易；显式开启类二买后的全区间执行链验收产生交易，但结论仍只是“探索性”，不是已经找到了可靠盈利策略。

## 推荐使用流程

### 1. 准备目标标的数据

1. 启动 `启动程序.cmd`。
2. 打开右侧“数据集”。
3. 扫描并导入目标标的历史 TXT。
4. 选择目标数据集，核对：
   * 标的和周期。
   * 覆盖时间。
   * `dataset_id` 和 `data_revision`。
   * 最好至少 504 个交易日。

如果只有某只票的一段历史，只能做探索。要评为“可靠候选”，还需要至少三个独立品种组。

### 2. 先筛选适合这只票的算法

打开底部“策略研究”：

1. 选择当前标的数据集。
2. 默认全选 15 个正式策略（13 个基础策略和 2 个结构+MACD 组合策略）。
3. 设置真实的：
   * 初始资金。
   * 手续费。
   * 滑点。
   * 合约乘数。
   * 保证金率。
4. 点击“一键回测所选 15 个策略”。
5. 完成后按下面顺序筛选：


| 指标          | 建议                             |
| --------------- | ---------------------------------- |
| 交易数        | 太少先排除，至少先看 20 笔以上   |
| 总收益        | 必须在真实成本后为正             |
| 最大回撤      | 建议不超过 20%                   |
| 期望值        | 应大于 0                         |
| Profit Factor | 应大于 1                         |
| Sharpe        | 越高越好，但需结合样本量         |
| Pareto        | 优先关注高收益、低回撤的前沿策略 |

先保留约 2–4 个候选，不要只选择收益最高的一个。

### 3. 查看胜率和收益明细

当前批量策略表主要显示总收益、回撤、Sharpe、PF、期望和交易数。点击底部“回测 ↗”会打开与当前 `dataset_id + data_revision` 精确绑定的独立回测页；胜率和单笔交易明细都在该页面显示。

对候选策略：

1. 记下策略名称和参数。
2. 点击“回测 ↗”打开独立回测页；原 K 线页保持打开，以便联动核查。
3. 使用相同数据、参数、成本和资金重新运行。
4. 查看：
   * `胜率`
   * `总收益`
   * `年化收益`
   * `最大回撤`
   * `Profit Factor`
   * `每笔期望`
   * 平均盈利/平均亏损
   * 最大连续亏损
   * 交易和权益曲线

交易明细默认占独立页面至少一半高度。向上拖动参数区与明细区之间的分隔条可以扩大明细区；参数区和交易表各自带滚动条。交易表会自动读取全部分页，双击任意一笔交易后，原 K 线页会把该笔交易的入场 K 线放到屏幕中央，并在对应 K 线上显示贯穿高亮线、价格锚点和“买入/卖出”标识。若原页面已经切换到其他数据修订版，系统会拒绝联动，避免把交易标到错误的行情上。

选择“只做第三类买点”时，参数区会显示可展开的“算法原理与买卖条件”。正式回测完成后，开仓和平仓行的“成交原因”来自该条成交实际关联的因果信号；“结构快照”只是入场当时的通用市场背景。因此“未匹配到通用结构快照”不等于没有三买信号，也不是平仓原因。

从 `third_buy_only@1.2.0` 开始，开仓行会逐项列出该笔信号实际引用的来源中枢 ID 与起止 K 线、`ZD/ZG/DD/GG`，向上离开段、第一次回试段及结束 K 线，回试低点与 `ZG` 的差值，以及 B3 确认 K 和成交量门槛。双击开仓行后，主图以蓝色虚线框标出来源中枢核心，以绿色标出离开段，以橙色和黄色端点标出首次回试及结束位置。旧正式 run 不会被覆盖；若看到“结构证据增强前”的提示，请重新运行一次正式回测。

交易明细按成交动作展示：每笔完整交易拆成原 ID 加 `-01` 的开仓记录和加 `-02` 的平仓记录。开仓行的毛盈亏、手续费、滑点和净盈亏显示“—”；整笔交易的数值在平仓行统一结算。双击 `-01` 定位开仓 K 线，双击 `-02` 定位平仓 K 线。

定位到历史交易后仍可正常浏览完整历史：向左拖到缓存边缘会补充更早 K 线，向右拖到缓存边缘并松开后会补充更新 K 线；可重复拖动直至数据集的最新一根，补数时当前视口保持不跳动。

回测操作区的策略参数、风险参数和运行状态使用中文显示。需要排查契约时可把鼠标停在参数名称上查看对应的英文 `snake_case` 字段；该技术字段只用于接口和运行记录，不影响中文操作。

指标口径：

* 胜率 = 盈利的已平仓交易数 ÷ 全部已平仓交易数。
* 总收益 = `(期末权益 - 初始权益) ÷ 初始权益`，已计入手续费和滑点。
* 年化收益从每日权益计算，不是把 5 分钟收益直接乘 252。
* 每笔期望 = 所有已平仓交易净盈亏的平均值。

例如“胜率 70%”并不一定好：如果平均赚 100、平均亏 500，仍可能亏钱。因此至少同时看胜率、盈亏比、PF、期望值和回撤。

### 4. 优化候选参数

打开底部“优化”：

1. 每次只优化一个候选策略。
2. 只给少量有经济意义的候选参数。
3. 使用训练—验证拆分。
4. 不建议单独最大化胜率，优先：
   * 最大化总收益或 Sharpe。
   * 同时约束最少交易数和最大回撤。
5. 保留验证集表现稳定、不是只在训练集突出的参数。

不要优化 `checkpoint_interval` 这类工程参数。

### 5. 做正式走步和可靠性验证

在“策略研究”顶部的“单周期可靠性研究”：

1. 固定一个候选策略。
2. 选择至少一个数据集；单标的可以执行完整研究但只能形成探索性证据，可靠候选仍要求至少三个独立品种组。
3. 勾选：
   * “走步样本外验证”
   * “执行与成本压力测试”
   * “统计稳健性与认证”
4. 默认使用：
   * 252 日训练。
   * 63 日验证。
   * 63 日步长。
5. 填写需要选择的参数候选值。
6. 点击“运行研究”。

重点看：

* 样本外收益和成交数。
* 盈利折比例。
* 最差折回撤。
* 参数是否频繁漂移。
* 2 倍成本后是否仍盈利。
* 延迟一根 K 线后是否仍盈利。
* Bootstrap 日均收益 95% 下界是否大于 0。
* 参数邻域通过率是否达到 60%。
* 最终等级是“探索性”“研究候选”还是“可靠候选”。

## 如何判断“某只票适合某算法”

比较合理的判断标准是：

* 目标标的多数样本外折收益为正。
* 样本外交易数足够，而不是几笔偶然交易。
* 样本外每笔期望为正。
* 回撤在可承受范围。
* 参数相邻档位仍有效。
* 真实成本、2 倍成本和延迟后没有立刻失效。
* 其他独立标的上没有完全崩溃。

因此最终结论应写成：

> “算法 A 在标的 X 的 5 分钟历史样本外测试中，完成 N 笔交易，胜率 X%，净收益 Y%，最大回撤 Z%，每笔期望为正；但当前证据等级为某级。”

而不是简单说“这只票适合算法 A”。
