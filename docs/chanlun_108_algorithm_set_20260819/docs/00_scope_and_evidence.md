# 范围、证据与整理方法

## 1. 目标

把108课中可执行的内容拆为四个层次：

1. **对象识别**：K线、分型、笔、线段、中枢、走势类型。
2. **结构事件**：延伸、破坏、升级、背驰、三类买卖点、中阴阶段。
3. **策略决策**：何时允许建仓、减仓、回补、持有或空仓。
4. **工程约束**：确认时点、价格精度、无未来函数、异常行情、成本与风控。

“各种可能的形态”不等于罗列所有历史图形。本包采用**完备分类**思路：凡能改变程序分支的形态，必须有类型、前置条件、确认事件、失效事件和镜像形态；只作为举例、没有新增分支的历史走势，不另造算法名。

## 2. 资料范围

- 已逐课扫描1—108课文本。
- 原课网页中共识别到24张图片，全部收录到 `assets/original/`。

- 其他课次主要是观念、市场评论、历史案例或未形成新判定分支，仍被纳入“已扫描”范围，但不强行为其制造算法。

## 3. 证据分层

### FORMAL

明确出现“定义、定理、原则、唯一划分步骤”或给出必要充分条件。例如：

- 第17课中枢、盘整、趋势与走势分解。
- 第20课中枢区间、级别扩张和第三类买卖点。
- 第62、67、77课分型、笔、线段与特征序列。
- 第91课笔的四状态及允许转换。

### DERIVED

由多个正式规则拼出的决策树。例如：

- 先用第17/20课建立中枢，再用第24/37课检查背驰，最后用第21课分类买卖点。
- 第100课三层级分类：低级别变化先发生，再判断是否构成上一级第三点。

### AUXILIARY

作者明确称“辅助判断”，或指标只替代力度/时间观察。例如：

- 第24、25、50课MACD。
- 第90课BOLL判断中阴结束时间。
- 第92课Zn中枢震荡监视器。
- 第106课均线强弱分类。

### HEURISTIC

原文使用“一般、往往、概率、经验”等措辞，或属于操作偏好。例如：

- 第31、55课资金操作建议。
- 第46课日内8根30分钟K线的强弱分类。
- 第74课政策风险应对。
- 第82课分型强弱与后续延伸概率。

### EXPERIMENTAL

工程扩展或原课明确认为不稳定。例如“三笔公共重叠形成笔类中枢”。第83、91课说明笔不能作为标准中枢组件，所以该对象只能进入独立命名空间。

## 4. 严格性策略

课程存在“先通俗、后精确”的演进。第72课明确说明：线段划分应以第67课特征序列的精确定义为准。因此冲突处理优先级为：

```text
后续明确修订/精确定义 > 早期通俗定义 > 案例描述 > 指标经验
```

每个算法卡必须包含：

- `source_lessons`
- `evidence_level`
- `inputs`
- `preconditions`
- `confirmation`
- `outputs`
- `invalidation`
- `forbidden_shortcuts`
- `mirror_id`（若有）
- `tests`

## 5. 不做的事

- 不把作者的“必然赢利”“100%”等表述当成现代实证保证。
- 不用一张静态截图替代时间顺序测试。
- 不把K线周期直接等同于走势级别。
- 不将MACD交叉、柱面积或均线穿越单独命名为标准B1/B2/B3。
- 不允许用最终高低点回填历史端点而不记录确认延迟。
- 不替用户决定杠杆、资金比例或实盘上线。

## 6. 质量门槛

一个策略只有同时通过以下门槛，才能从“研究”进入“可模拟”：

1. 几何结构测试全绿。
2. 实时逐bar回放与离线批处理结果在确认时点后一致。
3. 所有信号都能追溯到输入对象和源课规则。
4. 手续费、滑点、最小价位、停牌和涨跌停已进入成交模型。
5. 有样本外、走步验证和参数敏感性报告。
6. 任一辅助指标被关闭时，标准几何对象不应改变。
