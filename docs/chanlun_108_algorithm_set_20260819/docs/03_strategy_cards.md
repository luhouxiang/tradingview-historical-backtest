# 策略算法卡（人读版）

以下策略统一以“几何对象已正确确认”为前提。镜像做空/卖出逻辑并不代表所有市场允许卖空；执行层必须按市场制度裁剪。

## STR-001 固定级别五状态决策树

- 来源：18、20、21、49。
- 等级：`DERIVED`。
- 适用：选定一个操作级别，始终围绕最近已确认同级别中枢。
- 入场：`BELOW_NO_S3` 中出现该级别买点，或 `ABOVE_NO_B3` 确认B3。
- 持有：`ABOVE_AFTER_B3` 且未形成新中枢完成/同级卖点。
- 震荡：`INSIDE_CENTER` 只允许用次级别买卖点做差价。
- 退出：S1/S2/S3或向上走势完成；策略级别改变时先结束旧实例。
- 禁止：用单根K线在ZG上方直接判B3。
- 主要风险：中枢识别延迟、震荡升级、跨级别状态混淆。

## STR-002 只做第二类买点

- 来源：14、17、53、86、101。
- 等级：`FORMAL+DERIVED`。
- 入场：B1确认后，第一段次级别上升完成，再等待第一段次级别回试完成；回试终点为B2。
- 三分支：
  1. `B2=B3`：最强V型，回试不回最后中枢。
  2. `B2<B1`：允许但最弱；要求盘整背驰和内部完成，降低优先级。
  3. `B1<B2<B3`：一般序列。
- 退出：下一次级别上升不创新高或出现盘整背驰；若形成B3且向上不背驰，可转交趋势持有策略。
- 失效：回试尚未完成、并非B1后的第一次回试、B1本身仅为候选。

## STR-003 只做第三类买点

- 来源：20、21、49、79、86、107。
- 等级：`FORMAL+DERIVED`。
- 入场：选择级别；次级别走势向上离开中枢，随后**第一次完成的**次级别回试低点 `>= ZG`。
- 偏好：上涨第一中枢后的首次B3；已形成多个中枢后，更应警惕趋势背驰。
- 退出：下一次级别向上不创新高或盘整背驰；若非背驰并形成新中枢则持有到趋势背驰。
- 失效：回试低点 `< ZG`，或“第一次回试”已被消费。
- 边界：`low == ZG` 仍属于“不跌破ZG”，本包按闭区间确认。

## STR-004 中枢震荡差价

- 来源：24、33、38、39、45、49、92。
- 等级：`DERIVED`；Zn为`AUXILIARY`。
- 条件：当前中枢已确认，尚无B3/S3，操作能力和交易制度允许次级别执行。
- 买入：向下震荡段出现次级别底背驰/盘整背驰并确认。
- 卖出：向上震荡段出现次级别顶背驰/盘整背驰并确认。
- 强弱：`Zn>Z`偏强，`Zn<Z`偏弱；仅用于仓位和优先级。
- 停止：B3、S3、中枢升级、成交成本吞噬预期幅度。
- 禁止：Zn越过A/B就直接当第三点；原文明确说越界可发生多次。

## STR-005 同级别分解机械程序

- 来源：38、39、40、45。
- 等级：`FORMAL+DERIVED`。
- 方法：把走势唯一地分解成同级别完成段 `A1,A2,...`；比较 `Ai` 与 `Ai+2` 的同向力度。
- 买卖：奇偶方向按配置固定；同向后段不创新极值或出现盘整背驰时执行反向操作。
- 分支：若 `Ai+3` 破坏 `Ai` 极值，则等待新同级结构；未破坏则继续围绕原中枢。
- 级别升级：足够多段构成高级中枢时，关闭小级别实例并迁移。
- 风险：错误把未完成段纳入比较、因多义分解选择最有利历史划分。

## STR-006 区间套精确定位

- 来源：27、43、50、61、102、108。
- 等级：`DERIVED`。
- 起点：高层级走势已进入背驰段；不能仅因MACD缩短就开始。
- 递归：在背驰段内部寻找下一层同向背驰段，逐层下降，直到可执行层出现完成转折。
- 入场：最小执行层买点确认后的下一可交易时点。
- 停止递归：数据粒度、费用、T+1、滑点或流动性使更低层不可执行。
- 失效：任一层未创新极值、可比段不成立或背驰段尚未完成。
- 说明：它优化定位，不改变高层级买卖点类别。

## STR-007 三层级完全分类

- 来源：91、100、102。
- 等级：`DERIVED`。
- 输入：连续三个层级，例如L0/L1/L2的对象与状态。
- 原则：先等待最低层背驰/转折；再分类回拉是否构成中层第三点；中层完成后才可能改变高层。
- 仓位：仅参与自己能处理全部后续分支的最小仓位；无法处理某一合法分支则不参与。
- 输出：`WAIT_LOW_TURN`、`LOW_TURN_ACTIVE`、`MID_THIRD_POINT`、`MID_CENTER_CONTINUE`、`HIGH_CHANGE_CANDIDATE`。
- 禁止：从高层预判跳过低层确认。

## STR-008 反弹/回调分段操作

- 来源：47、56、98、107。
- 等级：`DERIVED`。
- 前提：理论只保证目标级别反弹至少形成一个该级别中枢，不保证第二个上升段创新高。
- 做法：目标为L级反弹时，用L-1级节奏处理；第一上升段完成即允许部分兑现，下降段结束再回补。
- 转趋势：第一中枢后出现B3且向上非背驰，转为趋势持有。
- 失败：出现S3、回拉严重破坏前结构或费用后无正期望。
- 镜像：回调时先卖后买。

## STR-009 底部/顶部构造

- 来源：82、88、99、108。
- 等级：`FORMAL+DERIVED`。
- 精确底部：B1之后到由其引发中枢首次出现B3或S3。
- 成功：B3；失败：S3。
- 粗略分型底：底分型区间；跌破最低点失败，站上区间上沿至少引出向上一笔。
- 最佳入场：不是见到分型区间就买，而是向下试探失败并出现可确认买点。
- 持有：底/顶之间的连接段按目标级别持有；不要在每个小波动反复切换。

## STR-010 大级别底仓 + 次级别短差

- 来源：14、31、40、45、55。
- 等级：`HEURISTIC+DERIVED`。
- 核心仓：大级别买点后持有，直到同级别卖点。
- 机动仓：次级别S1减仓、次级别B1回补。
- 配置：核心/机动比例必须外置；原文示例不是通用参数。
- 禁止：通过加杠杆或无限补仓维持“成本归零”叙事。
- 评价：核心仓与机动仓分别记账，避免用浮盈掩盖交易亏损。

## STR-011 均线“吻”旧系统

- 来源：11、12、14、72。
- 等级：`AUXILIARY/LEGACY`。
- 形态：飞吻、唇吻、湿吻；短均在线上/线下分别代表多/空排列。
- 候选B1：空排列最后一次缠绕后的背驰式下跌。
- 候选B2：多排列后第一次缠绕造成的回调。
- 限制：第72课明确将其定位为早期简化系统；不得替代后续中枢/走势严格定义。
- 用途：可作为筛选器或独立基线模型，绩效必须与标准缠论策略分开。

## STR-012 MACD零轴防守

- 来源：24、25、50、103。
- 等级：`AUXILIARY`。
- 规则：选择能力所能处理的最低周期；DIFF/DEA进入0轴下方时退出风险资产，重新站稳0轴后才恢复参与。
- 用途：面向不能执行结构算法的简化风险开关，或作为组合层风险阈值。
- 禁止：把它称为标准S1/B1；指标参数、周期和确认必须固定并样本外验证。

## STR-013 BOLL中阴辅助

- 来源：90。
- 等级：`AUXILIARY`。
- 超强区转中阴：从轨外回轨内，随后创新极值但不能重新有效进入超强区。
- 二买/二卖提示：滞后转向的轨道常成为首次回试支撑/阻力。
- 结束提示：某级别BOLL收口提示更低级别中阴将结束或升级，常伴第三点。
- 禁止：BOLL收口直接确认第三点；级别映射不是固定“一对一周期”。

## STR-014 Zn震荡监视与变盘预警

- 来源：92。
- 等级：`AUXILIARY`。
- 计算：中枢 `[A,B]` 中轴 `Z=(A+B)/2`；每个次级震荡区间中点为 `Zn`。
- 强弱：`Zn>Z`偏强，`Zn<Z`偏弱。
- 预警：Zn越过A/B、持续抬高却不能突破B、趋势型次级走势且末中枢在外。
- 结果：只输出预警和仓位上限；第三点仍由结构模块确认。

## STR-015 日内8×30分钟分类

- 来源：46、47。
- 等级：`HEURISTIC`。
- 一中枢：平衡市；按中枢形成时间分偏强/偏弱/转折平衡。
- 两个不重叠中枢：单边市。
- 无任意连续三根重叠：最强单边市。
- 约束：仅适用于原文所用8根30分钟的日内结构，跨市场交易时段、夜盘和午休需重定义。

## STR-016 均线等级与板块轮动

- 来源：106。
- 等级：`HEURISTIC`。
- 均线组：默认示例 `5,13,21,34,55,89,144,233`，必须可配置。
- 个股分类：按本次反弹尚未攻克的最小周期均线分为9类。
- 板块指标：成分股类别均值；越高越强。
- 轮动：N类趋势出现顶背驰时，转向已调整完或补涨候选。
- 风险：成分股幸存者偏差、复权差异、行业分类变更、参数过拟合。

## STR-017 风险与执行覆盖层

- 来源：31、35、41、45、50、55、74、98、100、103、107。
- 等级：`HEURISTIC+工程必需`。
- 规则：无杠杆默认；不借贷交易；固定操作级别；成交成本前置；未知分支无法处理则不参与；事件风险时按确认信号减仓而非预测。
- 仓位：策略只输出0—1的目标风险预算，不直接输出股数；组合层再根据波动、流动性、最大损失和相关性换算。
- 硬限制：单笔、单日、单标的、行业和组合最大损失；异常数据与无法成交时熔断。
- 审计：任何原文“必赚/最大利润率”描述都不得进入代码注释为保证性断言。
