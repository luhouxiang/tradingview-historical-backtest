# 风控与回测协议

## 1. 为什么“形态成立”不等于“可盈利”

108课给出的是一套结构分类与操作思想。实际收益还受这些变量决定：

- 标的选择与退市/幸存者偏差。
- K线复权、缺失成交、异常价与时间戳质量。
- 买卖点确认延迟。
- T+1/T+0、卖空限制、涨跌停、停牌。
- 手续费、印花税、点差、冲击成本、排队成交。
- 资金规模、集中度、相关性与尾部风险。
- 参数、级别与样本期选择造成的过拟合。

所以算法卡中的 `entry/exit` 是决策规则，不是收益保证。

## 2. 分层回测

### Level 0：几何单元测试

只验证包含、分型、笔、线段、中枢、走势类型，不计算收益。要求：

- 正例、反例、等号边界、极端跳空。
- 候选端点被替换。
- 批量与逐bar结果一致。
- 边界全部使用整数ticks。

### Level 1：事件回放

记录每个事件：

```text
event_id, object_id, status_before, status_after,
endpoint_time, confirmed_at, available_at, trigger_refs
```

重点检测未来函数：策略只能读当时已确认对象。

### Level 2：信号测试

对B1/B2/B3及镜像验证：

- 结构前提是否完整。
- 第一次回试是否只消费一次。
- 盘整背驰没有冒充趋势背驰。
- MACD关闭后几何信号不改变。

### Level 3：成交仿真

至少支持：

- 信号后下一根可成交K线。
- 价格限制与停牌。
- 量能参与率上限。
- 固定费率 + 点差 + 随成交量变化的冲击成本。
- 无法成交时的订单过期、撤单和降仓逻辑。

### Level 4：组合与风险

策略只给 `target_risk_weight`。组合层处理：

- 单标的上限。
- 行业/因子暴露。
- 同源信号相关性。
- 组合波动和最大回撤预算。
- 现金、保证金和不可交易资产。

## 3. 数据切分

禁止随机打乱时间。建议：

1. 训练/规则开发区间。
2. 固定验证区间。
3. 完全隔离样本外区间。
4. 多轮走步验证。
5. 不同牛熊、震荡、事件冲击和流动性分层。

若用指数当前成分回测历史，必须改用历史时点成分，避免幸存者偏差。

## 4. 指标

同时报告：

- 年化收益、波动、Sharpe/Sortino。
- 最大回撤、回撤持续时间、Calmar。
- 胜率、盈亏比、期望值、尾部损失。
- 换手率、容量、费用前后差异。
- 按形态ID、级别、市场状态、标的分组的绩效。
- 候选数、确认率、失效率、信号延迟。
- B1/B2/B3分别统计，不汇总掩盖。

“成本归零”“赚股数”只能作为记账视图，不能代替总收益、风险和机会成本。

## 5. 风险硬限制示例

本包不替用户设具体数值，但实现必须支持：

```text
max_position_weight
max_sector_weight
max_daily_loss
max_strategy_drawdown
max_order_participation
max_stale_bars
max_data_gap
max_open_signal_age
kill_switch_on_data_revision
leverage_allowed = false (default)
```

任何硬限制触发时，风险层优先于策略层。

## 6. 参数治理

- 所有参数写入配置并随回测结果存档。
- 不允许代码中隐藏“经验阈值”。
- MACD/BOLL/MA周期、力度比较方法、有效站稳根数都必须显式。
- 只在训练段调参；验证失败不能反复偷看样本外。
- 需要报告参数邻域，单点最优而邻域崩溃视为过拟合。

## 7. 上线闸门

```text
research -> replay -> paper -> shadow -> limited_live -> scaled_live
```

每级至少要求：

- 可复现构建与版本号。
- 数据/信号/订单/成交全链路审计。
- 与参考实现逐事件差异报告。
- 预设停机条件和人工接管程序。
- 实盘表现与回测漂移监控。

未通过成交仿真和样本外验证的算法只能标记 `research_only=true`。

## 8. 事件与政策风险

第74课强调政策风险不可准确预测。工程实现应采用：

- 事件日更严格的仓位/流动性上限。
- 跳空场景压力测试。
- 无法获得第一卖点时允许使用第二/第三卖点的执行分支。
- 不假设一定能在消息前成交。
- 不以消息方向替代图形确认。

## 9. 最低合规提示

不同司法辖区对自动交易、投资建议、市场数据许可和回测宣传有不同要求。上线前应由合规/法律人员确认；本包不提供法律或投资意见。
