### 笔端点的关键结论

- 顶分型的“顶”是其中最高点，底分型的“底”是其中最低点。
- 一笔连接按唯一划分程序保留下来的相邻异类分型。
- 同类分型竞争时，未完成向上笔会保留更高顶，未完成向下笔会保留更低底；端点因此是该笔划分下的有效极值。
- “线段端点可不是绝对高低点”不能反推为“笔端点也可任意不取极值”。
- 第106课“至少6个基本K线单位”属于后期时间下界表述；本包默认采用第77课可直接执行的“顶底分型之间至少有一根K线不属于两分型”作为几何约束，并把6单位作为独立校验开关，详见歧义文档。

## 互斥与包含关系

- 同一已完成本级走势在同一分解口径下只能是盘整、上涨或下跌之一。
- `DIV-TREND` 与 `DIV-CONSOLIDATION` 不能同时作为同一级别同一对比的标准标签。
- `B3` 只认离开后的**第一次**次级别回试；后续相似回试是震荡点或新中枢结构。
- `BARDO` 不是第四种完成走势类型，而是“尚未完成分类”的实时状态。
- `SEG-ODD-ENDPOINT` 与笔端点规则不冲突：它描述线段整体端点与线段内部全局极值的关系。
- `EXPERIMENTAL_BI_CENTER` 与 `ZS-NEW` 必须使用不同对象类型、不同信号前缀和独立绩效统计。
