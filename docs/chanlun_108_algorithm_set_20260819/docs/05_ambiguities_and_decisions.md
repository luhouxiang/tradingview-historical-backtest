# 口径歧义与工程决策

## DEC-001 笔必须取最高/最低，线段可以不取

**结论：是，但要限定对象与确认阶段。**

- 第62课定义顶分型的顶为最高点、底分型的底为最低点。
- 第77课给出同类分型淘汰程序：未出现有效反向分型前，更高顶/更低底会替换早先候选，从而得到唯一笔划分。
- 因此一条已确认向上笔的终点是该笔有效区间内被选中的顶分型极值，向下笔镜像。
- 第78课说“开始点并不是最高点”“最高或最低点不是线段端点”时，主语是**线段**。线段作为中枢零件时可再标准化为全段高低区间。

实现：`bi.endpoint_price` 必须等于选中分型极值；`segment.structural_endpoint` 与 `segment.range_extreme` 分字段。

## DEC-002 笔的最小间隔

相关文字：

- 第62课：顶底之间至少有一根K线。
- 第77课：至少有一根处理后K线不属于顶、底端点分型。
- 第106课：一笔至少延伸6个基本K线单位。

本包采用可验证的组合约束：

1. 端点分型成员不得重叠。
2. 两端分型成员之间至少有1根独立的处理后K线。
3. 同时记录从起点分型中心到终点确认所跨的基本单位数，并提供 `min_basic_span_units=6` 校验。

第3项的“单位”在不同代码库里可能按间隔数或覆盖K线数解释，因此配置必须命名为 `span_measure`，不得只写一个含糊的“5根/6根”。默认测试以第77课直接步骤为主，并对第106课单独报告通过与否。

## DEC-003 边界等于ZG/ZD是否为第三点

第20课原文是“不跌破ZG”“不升破ZD”。本包按闭区间：

```text
B3: first_return.low >= ZG
S3: first_return.high <= ZD
```

使用严格 `>`/`<` 的外部流派实现必须另建profile，不能悄悄改变标准profile。

## DEC-004 中枢核心能否滑动

不能。核心由最初三个连续次级别走势的重叠确定，后续是延伸或新中枢/升级。实现中 `ZD/ZG` 一经确认不可变；动态滑窗可以另算辅助区间，但不得覆盖核心。

## DEC-005 笔能否组成中枢

第83、91课明确说笔不能组成标准中枢，原因是稳定性不足。工程若为了旧项目兼容保留“三笔重叠”，命名为：

```text
experimental_bi_overlap
```

并要求：

- `standard=false`
- 不输出标准B3/S3
- 与标准策略分开回测
- UI显示不同颜色/标签

## DEC-006 早期均线买点与后期三类买点

第11—14课均线“吻”是早期简化系统；第72课明确说明后续形态学更严格。本包将均线系统保留为 `legacy_auxiliary`，不把其B1/B2名称直接映射成标准对象，除非后续中枢/背驰模块也确认。

## DEC-007 MACD是否定义背驰

不是。第24、25、50课均把MACD作为力度辅助。正确顺序：先确定走势结构和可比段，再选择能显示它们的指标周期。算法输出分两层：

```text
structural_divergence_candidate
indicator_confirmation
```

关闭指标不应改变中枢、走势类型或第三点。

## DEC-008 盘整背驰是否就是B1/S1

不是标准趋势第一类点。第27、37课强调真正趋势背驰至少在两个中枢后发生；一个中枢内/前后的力度衰减应标为盘整背驰。它可以产生可交易转折，但绩效和语义必须分开。

## DEC-009 走势级别是否等于K线周期

不等于。K线周期是观察显微镜，走势级别由递归结构决定。配置中分开：

```text
bar_timeframe
analysis_level
component_level
```

第46课日内分类、第90课BOLL周期和第106课均线映射属于特定观察法，不能反向改写结构级别。

## DEC-010 走势“唯一分解”与实时多义

第33、36课讨论结合律和多义性，第38、101、102课强调同级别分解/递归唯一性。工程处理：

- 批处理输出一个按固定profile得到的规范分解。
- 在线保留所有尚未排除的候选，但只允许一个 `canonical_confirmed` 分解驱动标准信号。
- 候选消失要记录失效原因，不能用最终分解回写历史可用性。

## DEC-011 中阴是否是独立走势类型

不是。它表示旧走势结束而新走势分类尚未确认的实时阶段，可按中枢震荡管理。BOLL、Zn只是预警；最终由第三点、中心升级或完成走势确认退出。

## DEC-012 “理论保证”如何进入代码

课程中的绝对化收益表述不得转化为 `guaranteed_profit=true`。可编码的只有几何后果，例如“标准背驰后至少回拉前中枢”作为待验证结构断言。交易收益仍受确认延迟、不可成交、费用和价格跳空影响。
