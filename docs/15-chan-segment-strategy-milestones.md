# 15 线段缠论指标与策略扩展里程碑

## 1. 范围与固定口径

本阶段依据 `chanlun_segment_strategy_codex_reference_20260804-20260805` 和 `docs/chanlun_108_algorithm_set_20260819` 推进。10A–10L 扩展以已确认线段为构件的单级别模型；10M 起只在存在显式上层对象关系时增加结构级别，不以多个 K 线周期代替级别。Python 是唯一算法实现；Go 读取缓存并提供 API；Vue 只做投影、批量绘制、对象树和定位。

沿用现有确定口径：标准中枢要求 `ZD <= ZG`，等号为点中枢；核心形成后冻结；`DD/GG` 是参与振荡构件的完整外包络；同级趋势按外包络严格不重叠判断；MACD 同方向柱面积只在结构成立后比较力度；理论端点必须等待后续反向确认段，所有对象记录 `known_at_bar_index`。

本阶段不实现需要跨周期或上下级别信号联动的：

- `multi_timeframe_core_plus_swing`
- 旧参考方案中需要跨周期联动的 `centre_oscillation_swing`（不影响 10K 基于当前标准中枢组成线段实现固定级别 `ALG-STR-004`）
- `small_to_large_B2`
- `accelerated_breakout_lower_level_B3`

## 2. 里程碑划分

### 10A：扩展语义指标基础

- 中枢增加 `analysis_level`、`component_kind`、`component_count`、`DD/GG/Z`。
- 新增 `movement_state`：盘整、中枢震荡、中枢上移、中枢下移。
- 新增 `center_monitor`：每条已确认中枢构件的 `Z/Zn`、相对位置与强弱；10S 已将早期的迁移提示替换为精确的 A/B 越界和双向楔形预警。
- 新对象进入 Parquet、缓存清单、因果事件、公共 API、回放重建、图表图层、样式选择和对象树锁定定位。

### 10B：固定级别中枢决策树

实现 `fixed_level_centre_decision_tree`，状态为中枢内、下方无三卖、下方有三卖、上方无三买、上方有三买；状态、阶段信号、交易信号和图表事件全部可视化。

状态：已实现。边界接触计入中枢内，严格关联当前中枢的 B3/S3 才允许开仓。回放前缀与完整运行同一事实流；回测完成后生成 `StrategyRunSource`，对象树逐项显示状态、阶段和交易对象，主图绘制状态及最终图表事件。

### 10C：趋势反转策略

分别实现 `downtrend_reversal_only` 与 `trend_divergence_reversal`，标准一买/一卖只来自已确认趋势背驰，不让盘整背驰冒充。

状态：已实现。`downtrend_reversal_only` 仅以标准一买开多、标准一卖平多；`trend_divergence_reversal` 以标准一买/一卖双向反转。类一买/类一卖被明确过滤。确认 K 线同时生成可定位的状态、阶段、交易与图表事件，前缀运行与完整运行保持一致。

### 10D：盘整背驰中枢回归

实现 `consolidation_divergence_centre_reversion`，显式区分回归中枢与转化为严格三买/三卖两个分支。

状态：已实现。只接受关联盘整背驰的类一买/类一卖，先建立回归中枢假设；价格进入关联中枢核心时止盈。若未回归而确认关联中枢的严格三买/三卖，则平掉回归仓并切换到对应三买/三卖方向，两个分支均生成可审计、可定位对象。

### 10E：三买中枢迁移持有

实现 `third_buy_centre_migration_hold`，从严格三买确认后进入，直到新中枢或同级上移趋势背驰退出；卖出侧镜像用于空头。

状态：已实现。严格三买开多、严格三卖开空；类三买卖不触发。持仓忽略中途类一买卖等同级噪声，在新同级中枢确认或相反方向标准一买/一卖确认时退出，全部状态与交易事件可定位。

### 10F：首中枢三买轮动

实现 `first_centre_B3_rotation` 的单级别部分。只使用当前级别已确认中枢、三买/三卖与盘整或迁移背驰，不引入低级别失败判定。

状态：已实现。一个方向周期内只执行首个严格三买/三卖，后续同向三类点生成“后续中枢已过滤”对象而不下单；相反严格三类点开启新的方向周期。持仓遇新同级中枢、相反标准趋势背驰或相反盘整背驰时退出。参考讨论中依赖低级别走势失败的部分按本里程碑范围明确排除。

### 10G：108 算法集三类点契约对齐

按 `docs/chanlun_108_algorithm_set_20260819` 的规范先消除后续策略依赖的边界差异：

- 第一次已完成回试按闭区间判断，三买为 `low >= ZG`，三卖为 `high <= ZD`。
- 等号、越界、未完成回试和确认时点分别建立自动化测试。
- 缠论算法版本升为 7.0.0，消费三类点的策略版本升为 1.1.0，旧缓存不复用。
- 公共信号类型不变，继续由 `ChanPrimitive` 在主图批量绘制并进入对象树。

状态：已实现。下一子里程碑先对齐 `INV-ZS-004` 的标准中枢闭区间与点中枢语义；完成几何层契约及版本验收后，再进入 `ALG-STR-002`“只做第二类买点”。策略只消费当前权威缠论事件，不允许重扫原始 K 线生成私有结构。

### 10H：标准中枢闭区间与点中枢

- 三条连续已完成线段的冻结核心满足 `ZD <= ZG` 即成立，`ZD == ZG` 保留为标准点中枢。
- 不为确认额外等待第四条构件；无交集和构件未完成仍不发布。
- 算法版本升为 8.0.0，所有标准中枢消费者同步提升策略版本。
- Go 范围读取原样保留等号边界，Vue 以零高度 `segment_zhongshu` 语义区域绘制并进入对象树。

状态：已实现。下一子里程碑为 `ALG-STR-002`“只做第二类买点”。

### 10I：只做第二类买点

- 新增 `second_buy_only`，只接受已确认标准 B2；`class_buy_2`、候选点和缺少已确认线段链的事件不入场。
- 最强、一般、最弱三种 B2 可独立启停并配置手数；最弱分支强制使用不高于另外两类的仓位上限。
- 入场后只检查与 B2 回试段端点相接的第一条已确认上升段：未严格创新高或确认顶背驰时退出。
- B2 同点或同来源中枢的 B3 已确认，且后继上升创新高、无背驰时发布 `handoff_to_B3_trend` 图表事件；标准卖点与 B2 来源修订仍能结束持仓。
- `trade_signal.quantity` 缺省为 1，执行模型按实际手数计算手续费、滑点、保证金、持仓、权益和盈亏，平仓在单向净持仓模型下全平。

状态：已实现。算法目录、回放/回测共用入口、前缀不变性、三分支、两个失败出口、数量执行和 Vue 参数/图表标签均有自动化测试。完整 AOL9 69,289 根数据可发现并执行该策略；当前权威事件终态没有标准 B1/B2（只有类二与三类点），因此该样本按规则产生 0 笔交易，而不把类二冒充标准二买。

### 10J：只做第三类买点

- 新增 `third_buy_only`，只接受当前固定线段级别的已确认标准 B3，并按对象 ID 一次性消费第一次回试资格。
- 已确认中心按同向严格上移关系计算上涨中心序号；首中枢 B3 为高优先级，后续中枢可禁用或降低仓位。
- B3 后首条已确认上升段不创新高或确认顶背驰时退出；创新高且无背驰后，新中枢确认转为趋势持有而不是立即退出。
- 趋势持有在趋势顶背驰、标准 S3、已确认回拉进入来源中心（含触及闭区间上边界 `ZG`）或 B3 来源修订时退出。
- 可配置确认 K 线最小成交量，只作为风险过滤器，不参与 B3 几何判定。

状态：已实现。算法目录、回放/回测共用入口、前缀不变性、首/后续中枢优先级、流动性过滤、创新高与背驰失败、来源修订、标准 S3、闭区间回拉和新中枢继续持有分支均有自动化测试。完整 AOL9 69,289 根数据产生 13 次首中枢 B3 开仓、13 次平仓及 2 次后继创新高持有事件；所有状态、交易和图表事件都带 `known_at_bar_index`，可进入策略对象树并在主图共享语义图层定位。

### 10K：中枢震荡差价

- 信号层新增活动中枢内部相邻同向组成线段的盘整背驰；只比较结构先确定的线段与同方向 MACD 面积，不由 Zn 或单根 K 线制造信号。
- 新增 `centre_oscillation_spread`，底背驰执行震荡买、顶背驰执行震荡卖，可分别启停多空并按 `Zn` 相对中轴的位置配置强/中/弱手数。
- 中枢核心宽度必须覆盖显式估算往返成本和最小净空间；Zn 越过弱侧边界且没有快速执行能力时过滤，单中枢进场次数受上限约束。
- 标准 B3/S3、中枢离开、九构件升级风险和来源事实修订停止震荡；独立策略平掉震荡仓并发布趋势移交事件，不复制趋势持有算法。
- 状态、过滤、震荡买卖、停止和趋势移交都生成因果对象，进入策略对象树与主图共享语义图层。

### 10L：同级别分解机械程序

- 新增 `same_level_decomposition_program`；固定操作级别以 Python 发布的已确认线段作为规范分解单元，首尾连续、方向交替并按因果首次确认顺序编号，不扫描 K 线或按终态历史重新分组。

- 后续 `Ai+3` 严格穿过 `Ai` 方向极值时发布“等待新同级结构”，未穿过（含等号）时发布“继续围绕原中枢”；两个合法分支都有显式状态和图表事件。
