# 原图视觉金样

视觉金样用于检查渲染、端点定位和模块边界；不能代替数值单元测试。

## V01：第62课图1—图2，基本分型

图片：`assets/original/lesson62.jpg`

- 图1：中间K线高点、低点都高于两侧，必须输出一个顶分型。
- 图2：中间K线高点、低点都低于两侧，必须输出一个底分型。
- 端点必须画在分型极值，而不是收盘价、实体顶底或均值。

## V02：第62课图3，共用K线

- 顶底分型虽然可各自出现，但端点分型共用K线。
- 期望：拒绝组成一笔，原因是结合律/成员重叠。

## V03：第62课图4，无独立K线

- 顶分型与底分型不共用K线，但二者之间没有不属于端点分型的独立K线。
- 期望：108课严格口径下拒绝成笔。

## V04：第62课图5，最小有效笔

- 两端分型之间有至少一根独立K线。
- 期望：可以组成最小有效笔。

## V05：第62课图6，包含关系

- 不允许直接在含包含关系的原始K线上识别分型。
- 期望：先按方向合并，再进入图7分类。

## V06：第62课图7，三K完全分类

- 四类依次为上升、顶分型、下降、底分型。
- 期望：只有第二、第四类输出分型。

## V07：第62课图8—图9，笔/线段边界

- 图8、图9讨论线段及线段破坏，不是放宽笔端点规则的依据。
- 笔模块不得输出 `segment`；中枢模块不得把图中的单笔当线段。

## V08：第69课月线分型取舍

图片：`assets/original/lesson69_1.jpg`

- 绿色向下箭头为顶分型候选，红色向上箭头为底分型候选。
- 带 `X` 的分型不进入最终笔端点序列。
- 自动叠图应保持有效端点上下交替，并能解释每个被拒候选的原因。
- 因原图未提供完整OHLC，本项只做人工视觉验收。
