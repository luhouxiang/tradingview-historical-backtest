# 线段趋势底背驰：九步算法与缠论 108 课对照

整理日期：2026-10-08。

范围：说明当前缠论引擎 20.0.0 的生产口径，以及它与 108 课原文的对应关系。本文只整理说明，不修改算法、契约、缓存或正式回测记录。代码判定优先于旧文档中的 legacy 描述。

## 1. 先说结论

本项目保留了“先有下降趋势，再比较最后两段同向下跌力度”的结构思路，但不是原文定义的逐字实现。

主要差异是：

1. 用线段作为外部比较单位，用笔中枢和笔级回试映射内部次级别证明。
2. 中枢构造允许共享进入段，但相邻迁移比较排除该共享首段；这不是第 20 课规定的排除法。
3. 主力度采用位移、速度和 80% 中枢基准跨度，不以 MACD 面积减弱为硬门槛。
4. 完成态背驰等待后继线段的可知时刻，因此图上的低点与实际确认时刻可能相隔很远。

所以，“项目判定成立”应理解为满足项目版本化的工程规则，不能直接推论“已完整证明原文所有级别、分解和区间套要求”。

## 2. 108 课怎样说明趋势底背驰

以下为原文要点的转述，不是全文转载。链接为原文转载页，非作者原博客；课次与正文已经核对。

1. **先确定级别和趋势。** 第 17 课以连续次级别走势类型的重叠定义中枢；完成走势只有一个中枢为盘整，至少两个依次同向中枢才属于趋势。下跌趋势中的背驰不能仅凭两段下跌形状判断。[第 17 课](https://chanlun108.cn/chanzhongshuochan108ke/17.html)
2. **中枢不只是两个矩形错开。** 第 20 课还检查围绕中枢的波动关系；核心错开而外围发生重叠，可能形成更大级别中枢，不应直接归入同级别趋势。该课用后 GG 小于前 DD 表述下跌延续条件。[第 20 课](https://chanlun108.cn/chanzhongshuochan108ke/20.html)
3. **比较下降趋势中前后同向运动的力度。** 第 24 课介绍 MACD 辅助判断：在趋势结构下比较同向柱面积，并观察中间中枢带来的黄白线回抽。面积较小不是脱离结构独立使用的信号。[第 24 课](https://chanlun108.cn/chanzhongshuochan108ke/24.html)
4. **审查 a+A+b+B+c 的级别和 c 的内部。** 第 37 课要求 A、B 同级，c 达到次级别并包含针对 B 的三类点，且至少两个次级别中枢；下降时 c 必须创新低。b 可以比次级别小，但不能比 c 的级别大；内部可继续用区间套定位。[第 37 课](https://chanlun108.cn/chanzhongshuochan108ke/37.html)
5. **不能将 MACD 机械化为唯一标准。** 第 25 课强调指标的辅助性质，并讨论快速走势、连续涨停等局限。另一方面，第 24 课给出末段尚在运行时辅助判断的方法，并没有要求一律等下一条同级线段完全确认。[第 25 课](https://chanlun108.cn/chanzhongshuochan108ke/25.html)、[第 24 课](https://chanlun108.cn/chanzhongshuochan108ke/24.html)

需要特别区分三个概念：

- 笔：结构基础单位之一。
- 线段：由笔及特征序列规则划分的结构单位。
- 次级别走势类型：原文递归体系中的走势类型，不是“任意一条线段”的同义词。[第 67 课](https://chanlun108.cn/chanzhongshuochan108ke/67.html)

### 符号不要混用

本文统一采用第 37 课的记号：大写 A、B 是两个中枢；小写 a、b、c 是同向外部运动。

```text
时间顺序：a ↓ → 中枢 A → b ↓ → 中枢 B → c ↓
外部比较：                  b 与 c
趋势关系：         B 相对 A 严格下移
内部核验：                                  检查 c 内结构
```

第 24 课也使用 A、B、C 表示“前段运动—中间结构—后段运动”。其字母与第 37 课的两个大写中枢不是同一命名体系；不能把第 24 课的 A 运动段误当作这里的中枢 A。

## 3. 当前工程算法：按 1、2、3 拆解

### 1. 取得已经确认的线段及线段中枢

主比较单位是线段。完成态流程从同一结构流取相邻线段中枢 A、B，要求两者已经确认离开，并有合法的离开段索引。

中枢初始核心来自连续三条已确认线段的正宽度共同重叠。前一中枢的离开段可以兼任后一中枢第一构成段，后续仍须独立满足三段重叠与确认规则。

这是一种对象分解方式，不等于已经证明每条线段都是原文所需的完整次级别走势类型。

### 2. 判断 B 是否相对 A 严格下移

必须同时满足：

```text
ZG_B < ZD_A
comparison_GG_B < comparison_DD_A
relative_dir(B) = DOWN
```

`comparison_DD/GG` 是项目的迁移比较范围：通常取中枢主体组成段的实际极值；有共享进入首段时将该段从比较范围排除，但保留在中枢构成与完整主体范围中。

因此，项目范围不是自动等同于第 20 课的 Zn 定义或全部围绕波动范围。即使上述条件通过，也只是通过项目趋势结构门槛。

### 3. 选出 a、b、c，检查连接与时序

- a：紧邻 A 第一构成段之前的同向线段，不允许跳过反向段向前找一条“好看”的下跌段。
- b：A 的向下离开段。
- c：B 的向下离开段。

A 的主体必须先于 B 的主体；B 从 A 的离开段或紧接的一段起算。完成态 c 还必须处在 B 三条种子段之后，且存在后继线段。

b 与 c 是实际力度比较对象；a 用于趋势链结构审查，不参与本次 b/c 力度数值比较。

### 4. 检查三段同向与起点递降

```text
direction(a) = direction(b) = direction(c) = down
start_price(a) > start_price(b) > start_price(c)
```

相等不通过。线段的可知时间也须按时序排列。

“三条起点严格递降”是项目为防止深回抽误拼趋势而增加的过滤条件；在本次核对的原文中，没有找到将其作为独立三起点公式的表述。

### 5. 检查 c 创出整条比较链的新低

```text
low(c) < min(low(a开始至c之前的所有相关线段))
```

不是仅比较 `low(c) < low(b)`；也不是 c 比 b 短就算背驰。这里 low 取线段实际价格范围，可能与结构终点价格不同。

没有创新低，不输出此趋势底背驰结果；其他背驰类型有各自独立流程，不能保证这个失败输入一定归入另一类。

### 6. 用端点位移和观测间隔比较下跌力度

当前主力度 profile 为 `price_displacement_speed_v1`。

```text
D_b = b起点价 − b终点价
D_c = c起点价 − c终点价
N_b = b终点在原始观测序列中的位置 − b起点位置
N_c = c终点在原始观测序列中的位置 − c起点位置
V_b = D_b / N_b
V_c = D_c / N_c
```

以下同时成立，记为联合减弱：

```text
D_c <= D_b
D_c * N_b <= D_b * N_c
至少一个比较严格小于
```

代码以整数交叉乘积比较速度，不必做浮点除法。

N 是实际记录的原始 K 线观测间隔数，不是分钟差；休市不补 K，缺失行情也不补 K。运动端点缺失、观测窗口不完整、位移或间隔不为正时为不可比，不能当作背驰。

### 7. 检查是否满足中枢基准跨度的 80% 覆盖条件

下跌使用各自中枢上沿作为基准：

```text
R_b = ZG_A − low(b)
R_c = ZG_B − low(c)
R_b > 0 且 R_c > 0
5 * R_c < 4 * R_b
```

R 与第 6 步 D 是不同测量：R 从中枢边界量到实际最低价，D 从结构起点量到结构终点，不能混用。

当前力度条件是：

```text
联合减弱通过 OR 中枢基准跨度严格小于80%通过
```

80% 不是原文常数。它不仅能覆盖位移与速度冲突，代码也允许在主关系为 `equal` 或 `stronger` 时通过跨度条件；因此不能称作“只修正冲突”。等于 80% 不成立，并且不能覆盖缺少结构、新低或完整可比数据的问题。

MACD 同向柱面积、DIFF/DEA 极值继续留档，但当前正式判定不要求它们同步减弱。旧 MACD 函数仍存在供对照，不能把函数默认参数误认为引擎当前调用口径。

### 8. 检查 c 内部证明，决定候选还是工程确认

内部 profile 为 `bi_two_confirmed_centers_type3_v1`：

1. 从笔中枢流取 `CLOSED` 对象，主体起止完整位于 c 内，且确认时间不晚于本次背驰可知时间。
2. 按主体时序选择至少两个不同、先后排列的笔中枢；允许主体边界相接，不允许重叠主体被重复计作两次证明。
3. 在 c 内找到首次向下穿过 `B.ZD` 的已确认笔：起点 `>= ZD`，终点 `< ZD`。
4. 检查紧邻其终点的首次反向向上回试笔；整笔实际最高价须 `<= B.ZD`，等号允许。
5. 首次回试失败不能用后面成功的一次顶替；相关笔、笔中枢都必须在当时已经可知。

两个笔中枢证明与首次守界回试同时通过，才标记 `standard_trend / confirmed`；不足则为 `segment_trend_candidate / candidate`。无笔流时相关证据为未核验，不伪造已通过。

这里的 `standard_trend` 是程序 profile 名，仍然含工程映射。代码没有据此完整递归证明这两个笔中枢之间构成原文次级别下跌趋势，也没有继续核验 c 内部趋势本身的背驰；不能将“数到两个笔中枢”解释成完整区间套已经完成。

### 9. 分开保存底部位置、确认时间与失效

- 完成态图形锚点：c 的结构终点 K 线。
- 标记价格：c 的实际最低价，不保证等于该终点 K 的最低价。
- 完成态可知时间：本次函数使用 c 后继线段的 `known_at_bar_index`，内部证明也须不晚于此时。
- 形成态：以当前已见行情修订 c 的观察候选，不升级标准结果。
- 后续修订：力度不再通过、结构改变等情形可使历史候选或结果标记失效，保留因果记录。

所以“标记放在很早的低点，但后来涨了一大截才确认”可能来自后继线段等待和内部证明，不代表程序在那根低点已经知道最终结果。策略不能按后来确认时间倒填成交到旧低点。

## 5. 数值示例：为什么c更短仍可能只是候选

以下是假设数字，非真实 AOL9 成交案例。假定趋势结构、递降起点和创新低已经通过：

```text
b：起点3300，终点3100，N_b=100，D_b=200，V_b=2
c：起点3050，终点2950，N_c=100，D_c=100，V_c=1
```

c 的位移和速度都小于 b，第 6 步通过。但 c 内只有一个合格笔中枢，或者首次反向回试升破了 B.ZD，第 8 步仍失败，因此保持候选。

反过来，假定 `D_c=120、N_c=30`，其速度为4，比 b 的速度2更快，联合比较是冲突；如果独立计算的正值基准跨度满足 `R_b=200、R_c=150`，仍有 `150<160`，当前工程可由80%条件接受力度减弱。不能将这种结果解释为“位移和速度都减弱”或“MACD面积必然更小”。

## 6. 自动交易模拟采用的是另一种确认门槛

不要把对象树的标准确认与“段结束自动模拟”混为一谈。

`SegmentEndDetector` 在对应线段首次因果完成时，复用权威结构与力度比较发出模拟决策；外部比较复用形成态上下文，不等待标准流程的完整内部升级。模拟决策明确留档 `standard_internal_proof_required=false`。

因此，候选层的结构／力度已通过、对应段刚确认结束时，模拟策略可能执行；这既不把对象树候选升级为原文标准背驰，也不证明已满足第37课全部条件。模拟默认收盘决策、下一根开盘成交，实际成交还有资金和执行器约束。

## 7. 看图时按这个顺序检查

1. A、B是哪两个中枢？级别、主体、共享进入段和比较范围分别是什么？
2. a、b、c各自起止K线和价格是什么？是否三段向下、起点递降？
3. c创新低的参照范围是什么？比较的是实际低点还是端点位移？
4. 力度通过的是联合减弱，还是80%覆盖？不要只看线条长度或MACD柱高。
5. c内两个笔中枢、离开笔与首次回试笔的ID是什么？是否已确认且在c内？
6. 标记锚点K、实际最低价K和 `known_at_bar_index` 是否是不同位置？
7. 当前是形成态、完成态候选、工程确认还是失效？成交来自标准策略还是段结束模拟？
