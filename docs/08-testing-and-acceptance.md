## 2. 样例数据测试

以 30#AO2609.txt 建立不可修改测试夹具或裁剪后夹具，至少覆盖：

- GB18030/GBK。
- CRLF。
- 标题、表头和尾部数据来源行。
- 21:45、23:05、01:00、09:05 的顺序。
- 零成交量。
- 结算价 0 视为 null 的源规则。
- 错误行号追踪。

若完整样例受体积或授权限制，保留具有相同边界情况的最小匿名夹具，并记录来源数据哈希，不随意改测试期待。

## 3. 时间测试

- 普通日夜盘。
- 周一交易日对应前一周五夜盘。
- 国庆、春节等长假后的首个交易日。
- 无夜盘品种。
- 跨午夜。
- bar_start 与 bar_end 配置差异。
- 缺交易日历映射时导入失败。
- 转换后 timestamp_utc 严格递增。

## 4. 数据导入测试

- 同一文件、同一配置重复导入得到相同 data_revision。
- 修改一字节、导入器版本、交易时段或日历后 revision 变化。
- 相同 revision 已完成时复用。
- 中断目录没有 _SUCCESS，不能进入 catalog ready。
- OHLC 错误、重复时间、负成交量按规则处理。
- 原始文件哈希在导入前后不变。
- Parquet Schema 和元数据正确。
- 空运行配置扫描 `SR701` 时自动生成白糖品种、23:00 夜盘模板和可证明的交易日历映射。
- 空运行配置同时扫描 `Y2609` 与 `YL9` 时只联网解析一次，生成唯一 `DCE.Y` 配置且两份源文件均可复用。
- 联网参数页应覆盖整数与小数最小变动价位；价格倍率等于 10 的有效小数位次幂。
- 重复扫描不重复追加或改写自动配置，已有人工配置不被覆盖。
- 首个夜盘交易日通过公开交易日序列补充前一交易日；查询失败时保持待映射，不使用自然日减一天。

## 5. 因果性测试

### 5.1 前缀不变性

对任意 N：

1. 仅用 bars[0:N] 运行。
2. 用完整 bars 运行。
3. 取完整运行中 known_at_bar_index 小于 N 的事件。
4. 两者逐条比较。

对已知事件，ID、operation、payload 和顺序必须一致。

### 5.2 检查点

- 从头运行到结束。
- 在多个检查点恢复运行。
- 最终事件、信号和状态完全一致。
- 算法版本不匹配时拒绝检查点。

### 5.3 回放与回测一致

同一策略与数据：

- 回放事件中的交易信号。
- 回测输入到执行模型的交易信号。

必须逐条一致。

## 6. 缓存测试

- 完全相同输入命中。
- 参数键顺序不同但语义相同仍命中。
- 默认参数显式/隐式处理一致。
- data_revision、算法版本、源码、参数、模式任一变化时失效。
- 没有 _SUCCESS 的缓存不命中。
- 并发相同 cache_key 只执行一个 Python 任务。

## 7. 回测测试

- 当前收盘信号默认下一根开盘成交。
- 最后一根产生信号但无下一根时不成交并记录原因。
- 手续费、滑点、合约乘数和保证金公式。
- 多空开平与持仓变化。
- 同根止损/止盈冲突规则。
- 资金不足拒单。
- 取消、中断和失败标记。
- 相同输入事实表 hash 相同。
- 成功 run 不可覆盖。

## 8. UI 组件测试

- 默认窗格权重 6:1:1。
- 拖动分隔线只改变相邻窗格。
- 最小高度约束。
- 双击恢复默认。
- 右侧和底部面板压缩图表。
- 最下方可见 pane 显示时间轴。
- 主图不可删除。
- 对象树显示/锁定/排序与绘制一致。
- 绘图存时间价格锚点，调整窗口后不漂移。
- 选择控制点高于其他业务图层。

## 9. UI E2E

关键流程：

1. 扫描并导入样例。
2. 打开 AO2609 5m。
3. 首次显示尾部 3000 根或数据总量。
4. 向左拖动触发一次预取。
5. 缩放、改变窗格高度不产生 Python 任务。
6. 添加 MA、MACD、成交量和缠论。
7. 添加矩形并在对象树重命名、隐藏、锁定。
8. 刷新页面恢复布局和绘图。
9. 创建回放，单步到阶段信号和交易信号。
10. 运行回测并查看交易、权益和图上标记。

## 10. 日志测试

## 11. 路径安全测试

- 绝对路径。
- ..。
- URL 编码后的穿越。
- Windows 盘符和 UNC。
- data_root 内指向外部的符号链接。
- 大小写差异。

Go 和 Python 都必须独立拒绝逃逸，不能只依赖另一端。

## 12. 性能目标

以下为首期本机验收目标，测试机器配置必须写入报告：

- 17,000 根样例首次导入不超过 5 秒。
- 热缓存读取 3000 根 K 线的 Go 服务处理时间 p95 不超过 200 ms。
- 本地首次图表可交互时间不超过 2 秒，不含首次数据导入。
- 平移、缩放、分隔线拖动目标 60 FPS，持续交互不低于 45 FPS。
- 10,000 个策略语义对象使用批量 primitive 后仍可交互。
- Vue 日志上传和 Go/Python 文件日志不使主任务吞吐下降超过 5%。

性能不达标必须先有可重复基准和剖析证据，不得先改变架构边界。
