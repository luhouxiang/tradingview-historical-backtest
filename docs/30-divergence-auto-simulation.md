# 16A 三类背驰自动交易模拟

## 验收范围

1. 趋势、外部盘整、中枢震荡三类使用 Python 20.0.0 价格—时间力度函数；MACD 辅助。对应线段在当时被权威引擎确认结束时评估并发布模拟信号，不等后继反向整段完成、整个历史结束或标准趋势内部级别证明。理论端点和段确认时刻分开，禁止在事后端点回填成交。
2. 独立策略 `divergence_segment_end_simulation`，不改变标准背驰对象的候选资格。三类可独立启停；交易规则固定到运行参数，默认每次一手，收盘决策、下一根开盘成交。同向不叠仓，来源失效在当时退出。
3. 复用公共 backtest API、Python 成交/资金/费用执行模型和不可变 run；回放按 known_at 游标展示结构、决策、实际成交、持仓与权益，后退和跳转重建相同事实。准备过程中可以计算因果事件流，播放速度不得影响交易事实。
4. K 线区域有可拖动速度条：左端 60 秒一根、中点 1 秒一根、右端每秒 100 根；播放、暂停、单步、跳转、退出。高速度按经过时间推进批次，绝不按浏览器定时器的次数伪造速度。
5. 展示正在运行的中文交易规则和每次信号/成交原因；未来交易和最终汇总不提前展示。配置资金、成本、手数和起止范围；数据修订/来源切换及任务过期响应均隔离。
6. 覆盖前缀不变性、段完成提前确认、形成态不成交、三类过滤、去重、反向动作顺序、next-open 费用成交、回退/跳转、速度边界和真实浏览器流程。

## 口径

“段结束”指当下已有结构证据确认线段结束的 K，不等同于事后看到的极值 K。模拟结论保存在策略阶段事件中，以 `segment_end_simulation_v1` 标识，标准背驰的次级别条件仍按独立指标事实展示。

成交输出使用已有 `chart_event` 的开放 payload，增加 `event_type=simulation_fill`、`action`、`quantity`、`fill_id`、`order_id` 和实际成交价格/成本。该类型仍由 Python 成交器发布；Go 传递事实，Vue 按已知游标投影。不新增跨进程 API。

准备完成后，浏览器展示逐 K 因果结果；全量计算用于准备事件索引，策略逐根计算时并不读取最终背驰表。

## 使用与交易规则

后端加载新版本后，底部“自动交易模拟”进入配置页。选择起止K、三种背驰、是否允许做空、每次手数、资金、手续费和滑点；准备完成后点击图表上方“播放模拟”。可暂停、单步、后退或按绝对 K 编号跳转；退出后恢复普通全历史显示。准备中的任务退出／换数据源时会取消，迟到响应不会写入新数据集。

- 趋势：同向 `a+A+b+B+c`、严格中枢迁移、起点单调及新极值仍须通过；只免去标准趋势内部级别证明和后继整段等待。
- 盘整：按现有外部 `a+B+c` 比较入口与离开段，不把内部摆动冒充外部盘整。
- 震荡：按同一中枢内部同向段比较。三个类别独立启停，重合时按趋势、盘整、震荡优先消费同一段一次；不因禁用趋势把它偷偷改标盘整。
- 力度：沿用20.0.0 的位移／速度联合减弱或严格80%基准跨度覆盖；MACD只辅助。
- 默认底背驰开多、顶背驰开空，每次1手；同向不加仓、反向先平再开。关闭做空后顶背驰只平多。来源段从权威确认对象中失效时退出。
- 手续费、滑点、保证金和资金校验由原成交器执行，图表三角及持仓使用实际成交，不把交易意图冒充成交。区间末端无下一根或资金不足会显示未成交原因，不回填到端点。

速度按滑块位置 `p∈[0,100]` 映射：左半为 `60^((p−50)/50)` 根/秒，右半为 `100^((p−50)/50)` 根/秒。定时器只唤醒显示，由经过的真实时间累计根数并保留小数余量；高速度可批量绘制，所有中间K上的算法决策、成交均保留。后台浏览器节流可能使屏幕批量追赶，不改变交易事实。
