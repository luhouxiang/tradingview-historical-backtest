# 缠论 108 课：背驰与买卖点的工程定义

## 1. 边界

本实现使用已确认线段作为次级别走势构件。Python 是唯一权威算法实现；Go 只读取结果，Vue 只按时间、价格与样式绘制。所有对象都保存理论端点与 `known_at_bar_index`，只有确认后才进入回放。

标准中枢由至少三个已完成构件形成：

- 核心区 `ZD = max(L1,L2,L3)`、`ZG = min(H1,H2,H3)`，按[第 18 课](https://chanlun108.cn/chanzhongshuochan108ke/18.html)与 `chanlun_108_strict` 的闭区间规格满足 `ZD <= ZG`；`ZD == ZG` 是点中枢，仍是标准结构对象。
- 核心区固定；延伸只扩大外围 `DD=min(dn)`、`GG=max(gn)`。
- 一个中枢是盘整；至少两个同级别、同向移动且外围区间严格不重叠的中枢才构成趋势。

## 2. 背驰

### 2.1 趋势背驰

标准结构为 `a+Z1+b+Z2+c`。程序采用以下全部条件：

1. `Z1`、`Z2` 时间分离；上涨满足 `DD(Z2)>GG(Z1)`，下跌满足 `GG(Z2)<DD(Z1)`。
2. `b` 是 `Z1.exit_index` 的同向离开段，`c` 是 `Z2.exit_index` 的同向离开段；比较 `b` 与 `c`，不得比较进入首中枢前的 `a` 与 `c`。
3. `c` 创出相对 `b` 的新高或新低。
4. 上涨只比较 MACD 正柱面积，下降只比较负柱绝对面积，且 `area(c) < area(b)`。
5. `c` 后的第一个已完成反向段确认其端点；发布时点不得早于该段完成。

顶趋势背驰产生标准一卖，底趋势背驰产生标准一买。MACD 只是结构成立后的力度比较器，不能单独生成背驰。

### 2.2 盘整背驰

单中枢结构为 `a+Z+c`，其中 `a` 是中枢前最近的同向走势（不能机械取可能方向相反的相邻数组项），`c` 必须是中枢真正的离开段 `exit_index`。`a`、`c` 同向且 MACD 同向柱面积减弱，随后反向段确认 `c` 的端点。

盘整的 `c` 可以创新高/新低，也可以连 `a` 的极值都未突破；它不继承趋势背驰的“必须创新极值”条件。盘整背驰单独标记为 `consolidation`：底盘整背驰产生类一买，顶盘整背驰产生类一卖，不冒充标准一买/一卖。当同一端点满足更严格的趋势背驰时，只保留趋势背驰。

## 3. 标准一、二、三类买卖点

- 一买/一卖：仅由已确认趋势背驰产生。
- 二买：一买后的首个已完成向上段，再后的首个已完成向下回试段终点；二卖反向。
- 三买：中枢向上离开后第一次已完成向下回试的最低价不低于 `ZG`，即 `low >= ZG`；三卖反向，最高价不高于 `ZD`，即 `high <= ZD`。等于边界按闭区间确认三类点。该口径依据[第 20 课](https://chanlun108.cn/chanzhongshuochan108ke/20.html)“不跌破 ZG / 不升破 ZD”的文字，并由 `chanlun_108_strict` 规格固定。
- 二类点与三类点可位于同一时间、同一价格，分别保存，不能互相删除。

## 4. 类一、类二、类三买卖点

“类”信号是本项目对非标准趋势起点的显式分类，不与 108 课中的标准一、二、三类点混用：

- 类一买/卖：盘整底/顶背驰的已确认端点。
- 类二买/卖：以类一为起点，沿与标准二类点相同的“首次反向走势 + 首次回试”顺序确认。
- 类三买/卖：严格三类点出现时，若同方向最近的反转起点是类一且之后没有同方向标准一取代它，则额外保存对应类三生命周期标记。它与严格三类点可以同点共存。

类标记表达“生命周期源自盘整背驰”，不是降低中枢或回试结构条件。

## 5. 二买、二卖及类二的强弱

标准二类点和类二类点使用同一分级：

| strength | 买点规则 | 卖点规则 |
|---|---|---|
| `strongest` | 与严格三买同点，二、三买合一 | 与严格三卖同点，二、三卖合一 |
| `normal` | 二买价格不低于一买 | 二卖价格不高于一卖 |
| `weakest` | 二买低于一买，但该回试段自身由盘整底背驰确认结束 | 二卖高于一卖，但该回抽段自身由盘整顶背驰确认结束 |

若回试创新极值且没有对应盘整背驰确认，则不发布二类点。该规则防止把任意局部反弹或回抽误标为二买/二卖。

## 6. 契约与图形

`ChanSignalPoint` 除原有端点、确认时点、背驰类型和 MACD 面积外，新增：

- `signal_class`: `standard | class_like | null`；
- `strength`: `strongest | normal | weakest | null`；
- `signal_type`: 增加 `class_buy_1..3`、`class_sell_1..3`。

## 8. 算法版本与全历史核验

算法 6.0.0 修正笔端点，7.0.0 把三类点边界改为闭区间，8.0.0 再按 `INV-ZS-004` 接受 `ZD == ZG` 的点中枢，并在三条构件全部完成时确认，禁止复用 7.x 缓存。使用 `trading-data/history/30#AOL9.txt` 的 69,289 根 K 线全历史逐 K 线运行 8.0.0，得到 3,034 笔、450 段、455 个笔中枢、64 个标准线段中枢、30 个背驰和 106 个买卖点；该样本没有点中枢和等号三类点，因此终态数量与 7.0.0 相同。等号语义由独立合成边界夹具持续覆盖。全部输出仍须满足确认时点不早于理论端点及事件因果约束。

算法 9.0.0 为 `ALG-STR-004` 补齐活动标准中枢内部的盘整背驰：在同一中枢内按结构顺序比较相邻同向已确认组成线段，只有后段 MACD 同方向面积小于前段才发布底/顶背驰；中枢的首次确认或延伸归属尚未知时不得回填到更早端点，Zn 不参与结构信号。完整 AOL9 69,289 根数据得到 229 个盘整背驰，其中 199 个端点位于关联中枢内部；由此得到 433 个买卖点（401 个类点、32 个标准点）。笔、段、笔中枢、标准线段中枢数量仍分别为 3,034、450、455、64。9.0.0 的新增对象与 8.x 缓存隔离。

算法 10.0.0 为 `ALG-STR-009` 在分型对象上增加中间处理后 K 线的闭区间字段
`zone_low_i64/zone_high_i64`。`price_i64` 仍是顶分型最高价或底分型最低价锚点，新增字段
不改变分型、笔、段或中枢几何，只让上层能够在不回扫原始 K 线、不复制包含算法的情况下
观察第 108 课所述粗略分型区间。两个字段进入因果事件、Parquet、Go 范围结果和公共 API；
旧检查点恢复时仅为兼容而退化为极值单点，新 10.0.0 缓存始终写出真实区间，9.x 缓存不得复用。

算法 11.0.0 将既有 Z/Zn 监视对象对齐 `ALG-AUX-004`。冻结核心 `ZD/ZG` 作为 A/B，
组成线段区间作为当前单级别下的次级震荡区间；中点以双倍定点整数保存，避免奇数 tick 和负数
价格被整数除法改变强弱/越界结论。前三个监视点统一以中枢首次确认时刻发布，后续延伸成对
确认，每个中枢最多九点。越界和楔形仅是辅助预警，字段明确禁止确认第三点。主图连接 Zn 曲线
并绘制 Z 中轴；10.x 缓存不得复用。
